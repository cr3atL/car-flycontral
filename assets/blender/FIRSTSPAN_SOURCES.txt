First-span candidate, 2026-10-23

Construction and sources
- build_firstspan_car.py -> live Blender MCP scene FirstSpan_GT_Source_v2 -> roadster-gt.glb.
- build_firstspan_coast.py -> live Blender MCP scene FirstSpan_Coast_Source_v5 -> firstspan-coast.glb.
- export_firstspan_scene.py limits export to selected objects in the active task scene. Each export includes only referenced meshes/materials.
- Both model scripts ran in the live Blender MCP process. No geometry was constructed offline. The original RX100 file was never saved or modified.
- normalize_firstspan_sources.py runs in a separate factory/background Blender and only packs those MCP scene libraries as ordinary, independently openable roadster-gt.blend / firstspan-coast.blend. This is packaging, not modeling.
- Rebuild in a live Blender MCP session with the model script executed via exec(compile(Path(...).read_text(encoding='utf-8-sig'), ..., 'exec')). Existing named scenes are deliberately protected against accidental overwrite; use a fresh task session for reproduction.
- First-span car: continuous body shoulder and real wheel-well Boolean openings; shared canopy/roof surface; four independent wheel pivots; modeled tire/rim/disc/caliper, diffuser and jet nozzles. Renderer drives front steering and signed wheel roll. Physical vehicle size and suspension response were preserved.
- First-span coast: irregular cliff silhouette and angular fractured rocks, terrain-following soil and grass patches, shrubs and trees. firstspan-coast-roots.json records roots sampled with exact barycentric interpolation of the exported terrain triangles. Visual meshes add no colliders.

Runtime integration
- src/roadster/visuals/hero-car.js loads the car GLB and preserves pivot transforms.
- environment.js loads coast GLB, local HDR, unified warm sunlight, IBL, shadows and atmosphere; sky.js renders a smooth clear atmospheric sky with a small local HDR contribution, avoiding magnification of low-resolution IBL cubemap texels. Original scenery batches are clipped only through the sample band; original track GLB remains byte-identical.
- ocean.js shades the existing sea mesh with moving wave normals, HDR reflection, sunlight highlights, near-shore color, contact foam, pier/deck shadows and haze. It has no physics input/output.
- public/assets/firstspan/visual-manifest.json binds coast and foam contacts.
- Sample coast z approximately62..330, including the forward background visible from the first-span chase camera; normal full route remains intact.
