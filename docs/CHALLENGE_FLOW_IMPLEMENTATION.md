## 精准按真实接地样本判定

`src/landing-model.js` 的 `assessLanding` 同时供真实入账与展示预测使用。三个模式一致，边界包含等号。

| 精准条件 | 阈值 / 单位 |
| --- | --- |
| 车身倾斜 | ≤18° |
| 车头与道路方向误差 | ≤25° |
| pitch、roll、yaw剩余角速度 | 每轴独立绝对值≤0.6 rad/s |
| 接地接近速度 | ≤4.6 m/s |

没有角速度求和门槛，不再用 `maneuverActive` 或 `lastActionEnd` 松手满0.28秒隐藏降级。持续输入仍按原推力施力；没有自动停转、补圈或摆正。稳定/重落地/撞毁的30°/65°、7/14m/s、40°/105°及yaw 1.5/3.5rad/s安全边界保留，真实碰撞保留。

安全路面上的精准与目标位置分开。`padHit` 只观察实际涂装落地区，显示“命中落地区”，不额外加分，也不影响1.2/1/0.5系数。教学无涂装直道不再算命中。Sprint仍要求越过该段实体并落进该段pad才能完成路线条件；在pad外的精准姿态不会被偷偷降成稳定。

## 松手后的预计落点

展示使用独立只读 `releasePrediction`：克隆数值状态，以原积分、残余喷气、松手刹转、现有辅助和独立缓冲求接地样本。克隆禁止递归展示预测和奖励副作用。实际控制、辅助窗口和缓冲继续读取原 `prediction`，没有反向使用展示结果控制车辆。

青色表示按松手后的趋势可精准，黄色提示仍需调整，危险使用红色断环和真实原因，缺口有明确“无安全地面”。状态里的姿态/方向/收势描述预测接地样本，所以高空仍倾斜时也可能预计精准。下降超限有单独原因。落地后中央和计分面板都读取真实判定原因，例如方向未对齐，不再把所有重落地称为姿态偏大。

单元检查覆盖边界、无pad精准、每轴独立、移除隐藏时间锁、预测和实际接地、辅助开关、缺口与有限roof。测试内1000步观察开关对照保持位置、速度、角速度、气压、缓冲和原垂直预测逐值一致；[主控独立旧版对照](challenge-flow-physics-comparison.json)另有190个普通输入样本逐值相同。

原约0.41m、55ms压下/75ms保持/400ms恢复的落地曲线、接地声和首0.53s保护保持。输入、评分/价格、音频、强速度呈现等12份保护文件与主控基线哈希一致。两个旧模式继续观察实际地面电驱恢复巡航，没有添加Sprint的152km/h电驱。

## 正式路线一次提交，几何与奖励分开

正常教学约20秒完成后，以当时真实位置为锚点，一次提交全部七组正式路段。教学延误时路线随锚点顺延，90秒时钟保持；没有到达的障碍不授分。路线提交后不为玩家移动或突然补出障碍。

`src/challenge-course.js` 提供同一份有限实体给画面与扫掠OBB碰撞。预告、接近激活奖励和物理碰撞分别处理；预告状态已有实体，已通过或失败的缺口仍是缺口。下一组在上一组接地时已存在，取消了旧的落地2.2秒后再生150米前方障碍的单组门控。

| 组 / 约定节奏 | 相对锚点z | 实体组合与基础按法 |
| --- | ---: | --- |
| 3 / 约24秒 | +150 | 五台施工车，最高2m、深8.5m；点按完整脉冲 |
| 4 / 约32秒 | +435 | 五车错列，后接45m处第二道矮栏；推进约0.55秒 |
| 5 / 约41秒 | +805 | 85m真实断桥、自然轨迹供气环、可选高环、宽平台；基础推进约0.8秒 |
| 6 / 约55秒 | +1330 | 矮栏与有限桥顶：宽16m、长65m、底7.8m；点按短喷 |
| 7 / 约63秒 | +1640 | 低栏与开放表演区、高环可选；基础点按，表演可延长 |
| 8 / 约71秒 | +1950 | 矮栏与有限升降闸；点按短喷 |
| 9 / 约79秒 | +2240 | 低车阵→36m缺口→有限低桥→宽落地区；推进约0.55秒 |

正式pad半宽11.5m。各环均在道路中心线，基础路线不要求空中横移，环可放弃。高低路线由实际车阵、缺口、有限roof决定，保留无高度上限的原物理。84–90秒为宽落地区和释放收尾；2次修复、90秒结束、空中待结算不入账保持。障碍独立100分、动作/得分环落地结算和原分值不变。

`end` 表示危险几何已越过，`rewardEnd` 单独记录可选高环窗口。障碍通过后仍可追环；落地后提示下一组，不会因为远端可选环而反复叫玩家起飞。桥内负距离提示保持低位直行。

基础按HUD黄区提示。断桥表演的PC按法是：推进约1.1秒→松推进、DQW约1.1秒→松手约0.15秒→推进约0.4秒→松推进、DQW约1秒→全部松手。接续中不插入截图或状态读取。触屏为推进先松开，再普通两触点：左区平转、右区斜拖双轴；两轮名义保持为1.0/0.9秒。

## 版本边界和失败原记录

四份完整90秒长测在最终供气布局修正前；基础路线记录也早于可选奖励窗口提示修正。最后确认首车阵旧环y3.5低于原速自然轨迹的车中心约6.79m，改为y6.5，半径由3.5统一到现有供气模型基准3.6m；同时移除了教学直道的无涂装pad标签。最终局部原速首车阵检查实际请求30、到账18、精准、零撞毁，序号和去重正确。99项规则在这些修正后重跑；没有声称四条完整90秒在小修后全部再跑一次。
