# 一跳体验实现与验证

> 本文保留2026-10-22的一跳对照基线及当时构建。当前连续三段与强速度候选见[SPRINT_IMPLEMENTATION.md](SPRINT_IMPLEMENTATION.md)，最新源冻结为sprint-runtime-freeze.json；下文历史构建与测试数不冒充当前版本。

2026-10-22，当前生产主包 `index-BzCm8Ukp.js`。[4173生产预览](http://localhost:4173/) → “自由练习”。本轮聚焦施工车阵、自由特技、真实补气与宽直道落地的连贯体验。61项单元检查及8项相关浏览器用例通过；用户两次指出落地偏轻后已加重，最终实际复试回复“这次有重量感了，先保留”。当前重量表现按此冻结，随后只修复尘雾的有效共享蒙版。

## 路线与真实判定

黄色起飞区z55–85，建议推进约1秒。五辆施工车横排在z120，车体由15个可见的底盘、驾驶室和货斗体积组成，绘制与碰撞共用 `one-jump-config.js`。半径7.5米的气罐环位于z139/y11.5。落地区z165–430、x在±7米内；目标完成需真实越过车阵、真实穿环、实际空中补入大于0并在落地区安全接地。真实道路仍宽26米，落地区外的正常接地不冒充目标完成。

气罐环请求30点，主表100/单次腾空实际60上限沿用原规则，穿环不会直接设置主表。与不同类别整圈补气合并时按实际量显示；不足0.1时用“补至满气”或小额/上限提示，声音降为轻提示。环收集去重，接地一次结算；撞毁、错过环、辅助关闭后的不良姿态仍给真实结果。R或按钮立即重试。

## 光影与喷气

黄昏方向光配1024阴影贴图，真实道路网格接收车和施工车阴影，原假圆影关闭。90秒赛道已有缺口会移除对应接收面，不在洞上画假地面。128立方反射探针只采集一次本地天空和城市，供车漆和玻璃使用，未下载环境贴图。

20组喷口读取实际平移/角推力的方向和大小，核心、气雾随实际车身姿态变换；制动及辅助回正也按实际输出显示。48个固定雾片、3个固定短光弧循环复用。光弧只在真实完整圈事件触发。所有粒子按仿真时间更新，暂停冻结，不生成动作、气压或分数。

## 接地重量返修

首版约0.036米，以及第一次约0.159米的返修，均被用户指出仍偏轻。第二次返修为一次更强的压入、短停和回稳，正常4米/秒冲击约0.41米，最大0.56米；55毫秒压入、75毫秒短停、随后400毫秒回稳，位置和视线轻微联动、地平线不转，系统减弱动态时关闭。

悬挂只调轮组局部位置，以真实车身高度、pitch/roll和轮胎半径投影到路面，限位在-0.55至-0.18米。累计角按等价周期判断，支持360n加小角度；没有把整车和轮胎一起压进地面，也不改物理姿态/速度。直接对Babylon车模的真实轮胎底部世界坐标验证，整圈后的轻倾角仍贴在真实平面。

每次安全接地从实际轮胎接触点发出低矮的暖灰宽扇形尘雾，沿路面向后拖开；原计分画布的接地点状白粒子和大圆环停用。正常每轮4片、重落地5片，受固定池上限约束。尘雾优先占用旧气雾槽，不在空洞或未触地轮胎下生成。雾片底缘从真实接触点开始，中心抬到半高，避免埋入路面；材质直接共享已绘制的软雾蒙版，修复Babylon克隆动态纹理只生成空画布造成不可见的问题。镜头不制造二次物理弹跳，落地计分不重触发。

## 声音时序

一个延迟解锁AudioContext，原8个固定计分声部保留，新增一套8节点声音图，只有2个持续源：柔化噪声和低频电机。持续喷气、角推力、松手制动均读实际力/角速；菜单、暂停、后台和静音停止输出，重试复用已有声音图。

接地首拍为110→45Hz、130毫秒下降瞬态，加178Hz短共鸣和120毫秒滤波轮胎摩擦，2毫秒攻击；重落地低频更低。接地后180毫秒底噪降至8%，随后120毫秒恢复，270毫秒后才进入得分音，入账面板也延后180毫秒。账本仍在真实接地时入账。主表实际补入小于0.1时不播放正常补气庆祝。音频不可用时仍可完整游玩。

这些是信号/状态/时序验证。当前工具不能人耳听取系统输出，未将波形或非零信号称为听感通过。

## 范围与复跑

`npm test`，`npm run test:jump`，`npx playwright test tests/browser/feedback.spec.js`，`node scripts/jump-scenario.mjs`，`npm run build`，`node scripts/jump-production.mjs`。

config/input/scoring/score-config/challenge-config与已确认控制基线哈希相同。simulation只增加prevX碰撞观测与落地x/z；新练习环境独立，保留90秒玩法。旧单圈/强制顺序/12点预算约定不恢复。CORE_ACCEPTANCE由主控维护，本轮开发未改。

手机触控是桌面Edge模拟，不代表真机GPU、iOS、温升或首次玩家体验。卡顿专项按本轮要求不开展，旧长帧未声明修复。重量感按用户实际复试认可保留；声音这里只记录客观输出，未作人耳听验。
