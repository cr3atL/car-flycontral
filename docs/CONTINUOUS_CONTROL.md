## 控制与布局

PC地面A/D转向，空中A/D平转yaw，Q/E侧滚roll，W/S前后翻pitch；同轴对向键抵消，三个轴可同时持续输出。旋转不读取“下一招/整圈目标”，没有待播动作队列。

手机复用左区：地面明确标为转向，空中明确标为平转。左区固定中心、8px死区，按住两侧即有持续值；从任意起按位置拖回可见中心都归零。力度=(距中心-8)/(区宽×0.25-8)，夹到[-1,1]。右区152×112 CSS px，位于推进键上方：↑后翻/↓前翻，←左滚/右滚，独立圆点和百分比置于文字间。右区以接触点为基准，各轴8px死区、38px满力度，斜拖同时滚/翻。力度保留到移动、回原点或松手，未使用fired一次性触发器。

667×375时左区约x20–160、中心x90；右区x487–639、y123–235，推进独立位于右下。844×390采用同样边距与尺寸。左方向区的固定中圈和移动小圈分开显示，避免把手指起点误当固定中心。右区方向点与↑↓/←→及当前力度不叠字；主提示在手机中使用两区说明，PC保留键盘说明。

常用流程为先推进升空、松开推进，再左右双拇指组合，不需要三指同时按。844和667原速CDP已用两个触点同时控制三轴，推进为false，之后正常接地。三触点仅补充验证兼容性。

## 保障和真实姿态

主气压0时不能按住继续主动旋转。独立制动只移除已有角动能，不反向驱动刷圈；默认提前松手后仍可辅助摆正。关闭“落地前辅助回正”确实禁用三个轴的常规回正，需自行摆正；角速度制动和独立垂直缓冲保留。实测关闭后30°可稳定、约100°重落地、接近反向可撞毁，未瞬转摆正。

有主气压时，垂直缓冲启动不锁角输入，过晚收势可以真实失败。yaw仅改变整车朝向，镜头继续参考路面前进方向；空中玩家左输入不再暗中横移，惯性向前。按姿态矩阵Ry(yaw)Rx(pitch)Rz(roll)算车体三轴包围体，已与实际Babylon渲染矩阵对照。地面评价结合车身上方向、相对道路前向、yaw角速与真实接触速度，接地不直接改角度/角速度。

100点主表+实际补满60的连续推进/侧滚路线已覆盖约333.5m峰高、23.6秒腾空，空罐正常接地；这是已验证路线，不是高度上限。相机及释放预测按新包络复核，不沿用旧231m结论。预测仍为1/120积分、75ms缓存；高飞8/12/16/20秒释放对照误差近浮点舍入。

## 计分与进度

每轴按非辅助的真实净转角计圈，同方向的短转、刹停、回中再继续保留部分进度。微小制动反向噪声扣净角度，不清空进度；真实反向超过0.035rad时，旧的未完成方向进度作废，新方向从真实转折处开始。没有累加绝对路程，左右半圈往返不能刷圈。

自动回正开始即丢弃对应轴未完成的玩家进度；其运动完全不计圈。松手或反向制动时原有惯性真正跨完剩余角度可以计。同向四次300ms、间隔600ms松手的6.74rad案例现在得到一条left，反向抖动反例为0；长按2.5秒计两圈，随后辅助回正不添圈。

roll左右共类别、yaw左右共类别，前翻和后翻独立；各类补给20/10/5，实际100/60双上限。气罐环30与450得分环独立。主要分值、重复衰减、倍率/RGB、实际落地一次入账保留；最佳键改为crimson-lift-best-score-v5-continuous-yaw，旧v3/v4不混比。
