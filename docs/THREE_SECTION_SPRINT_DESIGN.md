# 连续三段冲刺体验设计

日期：2026 年 10 月 22 日。状态：本轮设计定稿，尚未开发。

本轮解决用户提出的“操作能完成，但整段过程不够爽”：用连续三段组织危险逼近、喷气突破、空中选择、真实落地和再次冲刺。保留现有三轴操控与已认可的落地力度，新增精准落地后的短暂地面顺势加速。

三段依次为施工车阵、断桥补气、桥下收势。普通路线约 35–38 秒，包括最后的冲出直道；具体进度由实际位置和事件决定，不按秒播放固定动作。先作为自由练习中的连续样段，保留现有一跳作对照，之后再讨论怎样接入完整 90 秒挑战。

## 本轮固定的边界

连续按住、松手制动、反向输入、同时三轴与手机双拇指映射全部保留，不改转速、起转响应、喷气推力、重力或气压价格。不添加空中横移按键、自动整圈、动作排队或不可见高度上限。

地面起飞 18 点，空中短喷 10 点，持续推进 16 点每秒；主表 100 点、单次腾空实际补给最多 60 点、真实地面每秒回充 25 点，沿用现行规则。动作按原类别补 20、10、5 点，分数与落地系数沿用现版。

现行正常落地镜头约下压 0.41 米，55 毫秒压入、75 毫秒停留、400 毫秒回稳；实际幅度仍沿用冲击和落地等级的曲线，上限 0.56 米。低频下降瞬态、轮胎摩擦、真实接触尘雾和独立着陆缓冲保留。新反馈不能再叠加一次压沉。

下文坐标是首轮布局值，单位为米：z 向前、x 横向、y 为路面上方高度。基准巡航约 140 公里每小时，顺势目标约 154 公里每小时。布局须用现有物理走线校核；若净空或落距不成立，优先调整可见几何、提示窗口与落地区，不能靠修改现有操控、吸附轨迹或虚构补气把路线做通。

## 第一段 施工车阵

从正常起步进入，五辆施工车及其车顶轮廓提前可见。车辆之间的地面缝隙不构成可驾车穿过的通路，飞行是通过车阵的方法。黄色地面标识只承担起飞预告，不产生隐形弹射。

主要提示为“短喷越过车阵”。建议先比较点按与约 0.45–0.60 秒按住的自然路线，不继续把按满一秒作为所有玩家的统一答案。提示出现后立即能操作，不加蓄力等待。

普通路线直接飞越并落在宽区；特技路线可在净空中持续侧滚、平转或任意组合，再提前松手。车顶通过时给一次短掠过声和真实距离参照；只有满足现有擦障条件才给擦障分，不把普通飞越伪造成擦边。

这一段不放气罐环，把注意力留给起飞、原有动作补气和第一次落地。真实完成整圈时，气压表、对应喷口和短动作提示立即回应；不做整圈也不妨碍第一次体验顺势加速。

精准落地后自动得到一次顺势加速。视野前方逐渐露出断桥警示及远平台，玩家在加速直道上有时间看清下一段，而不是落地马上再次按推进。

## 第二段 断桥与高位补气

断桥边缘、缺失路面和远端平台在起飞前一起可见。桥下是真实空洞，没有接地回充、接收路面的假阴影或悬空安全落点。主提示为“越过断桥”，高位环用较弱的辅助提示“再喷可追补气环”。

主路线在 z505–535 起飞，建议从约 0.70–0.90 秒推进开始校核，然后松开越过缺口。不要求先完成动作或先穿环，满气出发、无特技也应有足够余量安全通过。必须验证普通巡航和上段顺势速度尚未完全退去这两种入口。

可选路线是在腾空后再提交一次现有空中短喷，争取通过 z625 的高位环，再落到较远的宽平台。先额外花气、再补回、继续飞到平台，形成看得懂的资源用途。再喷时机由玩家决定，不自动代喷；环也不把车吸向中心。

该环请求补 30 点，不承诺每次实际补满 30。比如进入环时主表 62、此前本次腾空已实际补 20，则实际补 30，结果为 92、本次已补 50；主表 94 时只补 6；主表 40、此前已补 55 时只补 5。满气或本次补给用尽时只给通过的轻提示，不播放大补气高潮。

每个环每次尝试只能触发一次，沿用现有有效穿环判定；发光外圈为补给范围标识，不另加碰撞惩罚。真实动作补气与环补气按事件顺序应用，不能为让环显得有用而扣气或挪用落地缓冲。穿过满气环仍算真正穿过，不能因为实际补入为零而判本段失败。

主路线和高位环路线都应落回同一宽平台，后者通常更靠后。气压不足时可以放弃环，主路线的正确姿态着陆仍受独立缓冲保护。高飞和连续组合仍然合法，屏幕不能以追环箭头遮住远端落点。

## 第三段 越障后在桥下收势

先越过全宽施工护栏，再在下降过程中进入检修棚架。地面护栏保证仍须起飞；棚架让玩家能感到“正在回到道路空间”，而不是在空旷天空等待落地。

主提示为“越栏后收推，准备落地”。建议先校核点按至约 0.60 秒推进的路线，允许在棚架前自由做动作，再自行决定何时松手。临近架体只提示“前方桥架”，不新增自动停转或强制摆正。

棚架底面、横梁和两侧立柱都必须看得清；立柱位于中央通道两侧，实际碰撞与可见结构一致。棚架外侧、上方如果有真实净空，可以绕过或飞越，不能把顶面向天空无限拉伸。主线通过架下不是限高规则，也不要求玩家用指定姿态穿一个窄洞。

玩家可在架下安全接地，也可稍后在出口落地。落地的冲击先响，轮胎与路噪接回来，随后顺势加速；从棚架阴影进入开阔亮处时，增加视觉释放感，但亮度变化不能淹没路面。

这一段不摆新气罐环，让玩家把视线放在横梁、落点和收势上。原有真实动作补气继续有效，空罐仍能制动和获得着陆缓冲。最后一次漂亮落地的意义是稳住后继续冲出去，不强迫追加动作。

## 精准落地后的顺势加速

### 触发与一次性规则

触发条件为：本段主要障碍已真实通过；本次腾空至少 0.8 秒；在本段精准落地区产生现有 grade0 接地；随后连续 0.12 秒保持接地且未撞毁。沿用现有姿态、车头方向、角速度及冲击等级，不放宽精准判定，也不要求必须做特技。

每段每次尝试最多一次，并绑定本次 flight 与本次 landing。悬挂回弹、轮胎抖动、反复擦地或在直道连续小跳，都不能再领一次。分数仍在真实接地时按现行规则入账，顺势加速的延迟不改变账本或补气。

### 推进参数

| 项目 | 首轮确定值 |
| --- | --- |
| 操作 | 自动兑现，不增加按钮、手势或资源条 |
| 动力来源 | 一小段额外电驱推进，不消耗主气压，也不生成升力 |
| 启动时刻 | 接地后 0.18 秒；条件失效则取消，不留待下次兑现 |
| 有效窗口 | 启动后 1.20 秒，包含建立与退出过程 |
| 目标速度 | 本段普通巡航的 110%，约从 140 到 154 公里每小时 |
| 加速方式 | 在原地面驱动之外，额外前向加速度最高 8 米每二次方秒；靠实际积分接近目标 |
| 建立时间 | 约 0.45–0.60 秒；不保证在任何入口速度下都瞬间到达目标 |
| 退出 | 最后 0.25 秒逐渐卸掉额外推进，随后按现有巡航控制自然回落，通常还需约 1.5–2 秒 |
| 方向 | 沿道路行进方向增加前进动力，保留实际横向惯性；不沿特技残余车头方向横向弹射 |
| 中止 | 再次离地、撞毁、重开或结束样段；离地保留已获得的速度，但立即停止额外推进；普通暂停只冻结 |

只施加推进和目标限制，不直接设置速度或位置，不修改转向灵敏度、抓地参数或气压。已有速度高于目标时不额外推，也不强制拉低到目标；下一段预告与预测落点必须使用真实速度。

普通暂停冻结剩余窗口，清掉按住输入，继续后恢复剩余部分；重开、撞毁和结束则清除奖励。

HUD 只短显“精准落地 · 顺势加速”，不再新增加速大数字、连击计数或第二次得分事件。稳定落地和重落地按原规则处理，不获得这次额外推进；失误后仍有正常驾驶和后续机会。

## 三段之间的安全衔接

每次预期落点之后至少保留 120 米明确可行驶道路。从精准区最晚落点到下一段最早起飞点，至少保留 180 米，并满足实际最高入口速度乘 4 秒的距离，取两者中更大值。按约 154 公里每小时计算，180 米约为 4.2 秒；名义布局两次衔接分别为 220 米与 205 米，预留额外余量。若飞行校核需要扩大落地区，须同步后移尚未提交的后续段，不能压缩这段读路空间。

下一段可以提前出现在远景，但“现在起飞”的主提示不能和上段接地、入账、顺势加速同时争夺注意力。加速建立时只显示下一障碍的简洁预告；接近其起飞区再切换主提示。安全直道可以有近处护栏、灯架和清楚标线提供速度参照，不放未预告的横穿车辆。

三段几何在进入对应预告范围前确定。一旦玩家看见主要路况，就不能为了迁就飞行而移动桥边、棚架或补气环；若异常入口缺少安全预告时间，该次不提交强制障碍。名义坐标因此是空间节奏的起点，不是无视实际速度的固定秒表脚本。

高飞越过一段或多段仍按真实通过与落地计分。没有在某段落地区着陆，该段不记作连续完成，也不给该段的顺势加速；不强行拉回、不空中结算、不把一次落地累计发成三次加速。需要完整体验三段时可重新尝试，飞行高度本身不受处罚。

## 镜头与声音节奏

### 驾驶与腾空镜头

常态追尾先试相对路面约 4.4 米高、车后约 13.4 米，视线指向行进方向前方。重点是增加路面与近景参照；手机上车体、前方通路和落点需同时可读，若屏幕约束冲突，以保留判断空间为先。

起飞响应立即发生，镜头垂直跟随以约 0.18 秒响应起步，允许车辆在画面中少量上移，随后跟上。常用路线车身中心尽量位于画面高度 55%–72%；高飞时启用完整跟随兜底，不能把车留在屏幕外，也不能因此限制上升。

镜头朝向取行进轨迹和前方通道，不追随特技车头平转，地平线不跟随横滚或翻转。临近下降时逐步让落点和平台边缘更清楚，提示贴近落点。所有阶段保持原速操作，不加入强制慢动作、冻结物理或绕车展示。

顺势加速允许额外视野扩大 3 度，约 0.20 秒建立、0.35 秒恢复；以实际加速和速度驱动，和已有速度视野采用单一上限，不把两个系统无限叠加。接地后的前 0.53 秒只保留已认可的落地镜头，新增加速视野最早在该时刻后展开，避免抢掉压沉和回稳。

### 事件的声画顺序

以真实接地为 t0，三段使用同一套落地时序：

| 时刻 | 镜头和画面 | 声音和玩法 |
| --- | --- | --- |
| 起飞前约 2–4 秒 | 看见障碍、起飞区和去向；近景掠过提供速度参照 | 电驱与路噪维持，不持续播放紧急警报 |
| 按下推进即刻 | 喷口与卸载同步出现，保持向前惯性 | 冷气攻击音立即响，不加输入延迟 |
| 进入惯性腾空 | 气雾随真实出力退去，保留道路参照 | 路噪退出，风声继续；持续推进或制动仍由实际力驱动 |
| 真正越过车顶或梁边 | 只在真实近距离经过时给短促掠过反馈 | 一次约 0.08–0.15 秒掠过声，同一结构去重；普通远距离飞越不伪造险过 |

| t0+0.055–0.130 秒 | 原有受力短停 | 冲击尾音衰减，确认接地，不重复触发 |
| t0+0.130–0.530 秒 | 原有缓慢回稳 | t0+0.18 开始有效顺势推进；底声由低位恢复，电驱随真实加速上扬 |
| t0+0.18 秒 | 入账面板按现有延迟进入 | 不新增第二笔精准落地分，也不重复发补气 |
| t0+0.27 秒起 | 保留现有入账表现 | 得分短音随后进入，音量低于接地首拍，不覆盖电驱变化 |
| t0+0.53 秒后 | 允许顺势视野平滑展开，远处下一段清楚可见 | 风声随实际速度抬升，避免再加一次爆炸式提示音 |
| 加速结束后 | 视野平滑恢复，切回下一个行动目标 | 平滑回到巡航声，不突然切断所有底声 |

第一段突出“车阵被越过”的一次突破；第二段突出“再喷—实际补入—落上平台”；第三段突出“进入架下—轮胎受力—冲出阴影”。不同段落不更换已认可的落地力度，也不靠每段越来越大的震动表示升级。

声音优先级为碰撞与真实接地、必要危险提示、玩家喷气与制动、推进底声、得分装饰音。音乐只承担背景和段落变化，不用音乐节拍驱动判定或延迟输入。静音、精简效果和减弱动态设置仍可用；减弱动态关闭新增视野变化与原落地镜头，不削减实际顺势奖励。

## 练习流程与失误处理

自由练习增加“连续三段”选择，保留原一跳对照。R 或重开按钮从第一段重来，速度沿用练习起步、主气压 100、分数与段落奖励记录清零。操作区不增加按钮。

练习撞毁后沿用短恢复过程，在失败段的安全起步点重新开始该段，主气压 100、清掉未入账链与顺势状态，前段已入账保留。重试不重复领取已经记账的同段障碍分，补给环按本次尝试更新；中断后完成可以练后段，但不标成一次连续三段成功。完整重开才重置这一轮的全部记录。

连续三段成功要求按顺序实际越过各主障碍，并分别在对应落地区完成安全接地；三次全精准可标“连续三次精准”，不另加新分值。漏环、没做特技、稳定落地都不会单独判失败，只影响现有得分或顺势奖励。第三段接地后先完成冲出直道，至少 2 秒后再出现简洁完成信息和重试入口，避免用大结算面板打断最后一次加速。

这些是练习样段的新规则；本轮不改 90 秒正式挑战的修复次数、成绩存储、结算或评级。

## 后续开发范围与验收

后续一轮只实现三段布局、一个高位补气环、地面顺势奖励与对应镜头声音衔接。复用现有车模、三轴、气压、判定和落地表现，不同时重做姿态积分、动作分值、评级或整座城市。

| 项目 | 必须实际验证的结果 |
| --- | --- |
| 基础可达 | 三段在当前操控下均有无特技安全路线；第二段可以跳过高位环；净空按完整车体校核 |
| 真实选择 | 第二段直接飞越与再喷追环都成立；第三段可以架下收势，也允许利用真实净空高飞 |
| 保留操控 | PC 三轴持续、反向、选择性松开，以及手机双拇指组合均与当前基线一致 |
| 补气账本 | 真实动作与环的顺序、100/60 上限、小额、满气、耗尽、去重和失败重试一致；没有虚构补满 |
| 顺势动力 | 只在合格的真实接地后一次触发；真实前向加速度与目标可测；离地不再施加、无瞬间改速、无气压开销 |
| 奖励边界 | 稳定或重落地、小跳刷取、反复触地、撞毁、暂停继续、重开和高飞跨段都按上述规则处理 |
| 原落地力度 | 55/75/400 毫秒与原冲击幅度保持，新的视野和声音不覆盖第一拍、不多触发一次压沉或入账 |
| 衔接安全 | 以带顺势的真实速度进下一段，仍有至少 4 秒预告和足够可行驶空间；障碍不会在看见后移动 |
| 连续体验 | 玩家能说出三段各自的高峰，空中没有明显无事可做的等待，第三段落地后愿意继续冲出去 |

原速实际玩完整三段，再与现有一跳重复三次比较。测试通过只证明规则；本轮体验是否达标，以“整段更想继续玩”的实际反馈为准。手机尺寸与真实手机分别记录，卡顿专项继续不在本轮范围内。

| --- | --- | --- |
