## 布局与状态

PC保留3%边距：上方中央时间/进度、右上总分/暂停、左下速度/气压、左上实际剩余修复。九段挑战显示真实九组进度与剩余时间；Sprint显示三段及用时；练习显示用时，不套用九段或90秒。修复数量只在有此规则的挑战中显示。

| 状态 | 呈现 |
| --- | --- |
| 地面 | 一个投影到实际前方障碍的名称/距离。黄色区由赛道表达；操作窗口保留点按或0.55/0.8/1秒等必要提示。教学用“Space推进”“轻点Q”“按住Q”。完整键位移到暂停页。 |
| 空中 | 右侧描述词、真实累计分、最多3条逐条进入的真实得分记录。使用原score-config档位，2000起RGB；单个倍率解释行分与累计分的关系。真实补气量紧贴气压表。 |
| 准备落地 | 下降且松手预测接地≤1.6秒时收起动作列表、弱化仍在显示的累计分。显示一条松手/接地时间和预计精准或真实主因；危险可提前出现。无安全地面只显示危险原因，不称“0秒后接地”。 |
| 接地 | 首0.53秒保留冲击；之后在右侧展开真实等级/原因和实际入账数，短计算式后汇入总分。无待入账分只短暂显示真实结论，不造bank、“+0”或零乘式。完成/失败后保留可点击重试。 |

两秒无新增得分后面板退场，待结算分仍保留，真实接地时重现。撞毁显示连击中断，自动恢复后的旧grade3记录不进入成功结果。R和点击重试复用原重开逻辑，菜单/重试/切模式清理旧显示。手机保持原布局、触控、教学和触屏暂停说明。

## 预测车形与真实点

路面车形使用预测朝向，区分赛道pad长线。原追逐视角会遮住小轮廓；遮挡时显示无遮挡车形，并用虚线连接到真实投影点。箭头明确车头，危险是红色断裂轮廓且有文字。目标点未平移，镜头、预测z、姿态与缓冲未改。

投影函数会复用结果对象，最终实现先保存落点坐标副本，再投影实车。独立检查得到实际落点y=443.61、实车y=473.39、HUD端点y=443.61，避免连线误指车顶。车形使用有符号预测朝向；辅助关闭的实际偏转也可辨别。

唯一保护文件例外：在既有 `predictReleaseLanding` 克隆接地返回对象增加 `heading:g.yaw+g.heading,pitch:g.pitch`，只供呈现。移除此字段可恢复原文件精确SHA。其余20项主控保护文件哈希相同。[旧版与当前360样本对照](pc-hud-physics-comparison.json)没有位置、速度、角速度、气压、缓冲等数值差异。

## 时序与保护

`src/hud-model.js` 只消费计分日志和既有状态。实际结算、声音、辅助/缓冲时钟不变；PC总分的显示转移独立于实际总分。原约0.41m、55/75/400ms落地曲线、110→45Hz接地声、三轴连续输入/刹转/反向、100/60气压、20/10/5动作补给、路线和奖励保持。

原速记录覆盖最多3行、两秒无新分时隐藏且待结算仍在、首0.53秒面板隐藏；首次结果出现在实际接地后0.5333秒。单测同时检查数学边界、真实倍率、无bank接地、崩溃恢复、危险原因、模式时间/进度、补气和重置。
