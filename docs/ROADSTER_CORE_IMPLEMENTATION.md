# Roadster 核心原型实现与验证

2026-10-23。独立入口 `/roadster.html`。原有试验场仍位于 `/index.html`，入口菜单可直接进入 Roadster。

## 实现

场地来自 Blender 导出的 `public/assets/roadster-lab.glb`，对应的碰撞合同为同目录 `roadster-lab-layout.json`。运行时没有创建替代道路或平台。车辆为原创灰盒。场景使用 Babylon 左手坐标，取消 glTF 自动根节点转换后，资产、物理、镜头和输入均采用 X 向右、Y 向上、Z 向前。

`src/roadster/` 与旧版本运动规则分离：

| 文件 | 职责 |
| --- | --- |
| config.js | 实际运动、气压与接地参数 |
| simulation.js | 120Hz 固定步长运动、碰撞、恢复点、出口、事件及同规则预测 |
| geometry.js | 旋转后的整车轮廓、平面/坡道高度和支撑判定 |
| input.js | W/S/A/D/空格及两个独立捕获触点 |
| world.js | Blender 资产、原创车、真实投影、跟随镜头、喷气与预测轮廓 |
| audio.js | 按实际施力变化的基础喷气/风声及接地瞬态 |
| main.js | 菜单、暂停、转屏、生命周期、HUD 和只在开发模式提供的诊断入口 |

地面 W 为手动油门；S 停稳后保持制动，松开再按才倒车。转向依赖实际速度，原地不旋转。离地后 W 前推、A/D 沿运动参考方向施加侧推，S 沿水平速度反向减速，不控制下降。空格连续向世界上方施力，推力平滑建立。所有喷气共用气压并按实际推力付费，无独立救援气量、旧版限高、技巧补气、计分或评级。

预测复制当前完整运动状态，持续当前输入，用相同 1/120 秒步长、有限气压和碰撞几何推进至首次接触/碰撞；不修改本车。轮廓覆盖实际车轮宽度和前唇。三角支撑可接地，完整四角支撑才显示安全、确认恢复点。离开台沿时，离台面短暂豁免仅延续至车体清开原台面，防止后悬误撞；其他平台底面和侧面仍碰撞。正常地面跨面同步更新 surfaceId 和坡度。

地面无实际喷气后延迟 0.35 秒恢复气压，普通路面 7/秒、标记补气区 28/秒。接地稳定 0.55 秒、完整支撑且远离边缘并低于 12m/s，才确认恢复点。撞毁等待 0.95 秒后恢复，气压满、速度和输入清零。碰撞原因在复位后保留 3 秒。整场重开清除路线记录；暂停不补算后台时间。

## 验证口径

单元测试与固定步长诊断证明规则一致性；不能作为人工试玩或实体手机手感结论。`scripts/roadster-native.mjs` 使用 Edge/Chromium 原生键盘或两个独立触点驱动实时渲染循环。它只读取开发状态，以普通输入在平台上转向、缓冲下降或驶向出口；没有调用 advance、setManual、写位置/速度/气压或触发完成。自动状态反馈控制不能冒称人工操控。

每次原生记录包含实际输入的墙钟时间、已观察仿真时间、位置、速度、姿态、气压、接地事件和完成结果。三次连续的最终序列与早期失败分别保存。完整两跳要求平台 landing、补气至满、第二次 takeoff、far landing、complete 均真实发生，飞越不计。

`scripts/roadster-lifecycle.mjs` 检查 667×375 与 844×390：独立斜推和抬升、右指抬起保留左指输入、滑出后释放、原生 touchCancel、暂停冻结、转屏清输入并保持暂停、重开清记录。blur 用合成事件检查接线，不能代替真实系统切后台。

最终结果和源码/资产散列以 `roadster-final-validation.json`、`roadster-freeze.json` 为准；本说明不是提前宣告所有验收通过。

收尾结果：PC、915×412、667×375 的三条路线九组均各连续 3 次完整完成，共 27 次自动原生输入完成；平台路线都包含真实平台接地、补气、第二次起飞、对岸接地和出口。原生改道和全地面回程各 1 次通过。起点/低台撞毁复位通过，观察到撞毁至恢复分别约 825/951ms。667×375 与 844×390 生命周期检查通过。开发侧和主控独立全量检查均为 155/155，通过数不替代人工可用性结论。

最后一轮在主控全量检查之后只修正呈现：重开/复位镜头立即对齐车头，下降缓冲提示保留预测目标名称。运动规则、输入、配置和测试没有再变动。最终构建由主控继续独立生产检查。

JSON 和截图受既有 `.gitignore` 规则影响，保留在本地工作区；冻结清单包含这些文件，交接不能只依据 `git status` 判断它们是否存在。
