# 滨海立交试驾区实现

本轮沿用 `/roadster.html`，旧 `/index.html` 与三轴、评分、旧落地系统独立保留。场景使用主控从 Blender 导出的 `coastal-interchange.glb` 和 version 2 布局，运行时没有生成替代道路、碰撞台或额外关卡。

## 几何与接触

`geometry.js` 支持凸多边形和矩形，兼容两种顶点绕序；margin 为到真实边界的垂直距离。平面高度同时包含 `slope`、`slopeX` 和各自原点。碰撞先做范围排除，再对整车旋转足迹与实际多边形裁剪；弯道包围盒中的空气不会变成路面或墙。

支撑来自相邻面联合。四角命中只是必要条件，安全足迹还需由同高度的多边形并集完整覆盖；通过逐面扣除未覆盖的凸片避免把重叠面积重复计数。接缝不作为外边界。当前车体半宽1.15m、半长2.05m、高1.45m，覆盖实际车轮和前唇。预测使用相同足迹、坡面、碰撞和有限气压。

地面跨面直接继承新平面的切向竖直速度 `vx*slopeX + vz*slope`。落地冲击按相对坡面的竖直速度计算，水平速度由轮胎逐渐抓正，未瞬间清零或转向。离台豁免仅覆盖刚离开的接触面，在车体清开面顶、边界或底面后结束。斜坡内部车尾先接近较高面顶时不会被误当作侧面墙；真正底面/侧面和护栏仍参与碰撞。

16m空间分桶减少密采样路面在每步和预测中的查询量；布局对象加载后保持静态。

## 操控与气压

PC与手机保持同一套输入：W/前推为地面油门、空中前推；S/后推为地面制动、空中沿水平速度反推；A/D或横向摇杆为地面方向、空中侧推；空格/右按钮独立向上抬升。摇杆X/Y独立，后斜拉可组合反推与修正，不增加必需按钮。输入控制器沿用已验证的捕获、取消、失焦、暂停和转屏清理。

version 2的抬升上升响应为12/s，约0.19秒达到90%，按下第一步已有实际喷流和音色，松开保留上升惯性。其他喷流响应22/s。小侧向输入采用较细的非线性映射。无横向输入时的空气侧向阻尼只移除动能，不提供免费推力，也不恢复气压。

version 2高速轮角降低，普通地面电机采用40m/s软功率衰减参数，没有硬截断速度。地面发动机不消耗气压。抬升、前推、侧推与反推按实际平滑推力共同付费；落地后残余喷流仍付费，停止喷气后才恢复。补气带可在移动中经过，无等待满气或技巧奖励门槛。

重落地保持原有短促压沉和一次回稳。喷流朝向根据实际施力参考方向绘制，反推喷流跟随实际水平速度。音频分别读取抬升、侧推、反推和前推实际推力；未宣称主观音质或真机听感已验收。

## 路线、恢复点与镜头

阶段根据实际支撑面的 `group` 和 `route` 更新，不再假设只有旧低台、高台与对岸三个ID。高架、下坡、出口连续向前。出口要求真实地面跨过指定出口线，允许地面绕行汇入；飞过出口不算完成，不依赖伪造的 far landing 次数。

稳定安全接地0.55秒后，version 2允许34m/s以下移动激活同组附近恢复点。整车扩大0.35m后仍需在联合路面内，配置的恢复位置也需完整安全支撑。下层接地不能激活上方高架恢复点。复位清输入、速度和推力，气压满，朝向采用对应恢复点。

镜头不按输入自行转车，不锁定路线。水平跟随实际运动，保持稳定地平线。进入检修区前平滑提高视点，接近高架时世界高度约10.6m，升空后随车自然接续，能提前看到高架顶面。落地反馈不锁操作。深红简化车体仍在原有物理尺寸内，场景雾减轻、日光略暖。

## 验证边界

`coastal-diagnostic.mjs` 与 `coastal-ground-diagnostic.mjs` 是从正常出生点发出合法指令的固定步长反馈诊断，没有位置、速度、气压或完成注入。诊断不能替代原生操控或人工试玩。

`coastal-native.mjs` 用 Edge/Chromium原生键盘或两个独立触点驱动实时循环，只读取状态辅助转向。PC、667×375、844×390主线已有首轮完整通过记录：真实首跳落地、S弯、高架侧修与反推、高架接地、下坡和出口。没有为测试在游戏内添加自动驾驶。每次记录保存输入墙钟时间、仿真状态、资产/规则散列、接触事件、截图和失败。

`coastal-lifecycle.mjs` 区分触点取消/抬起、转屏、暂停和blur接线。浏览器尺寸/触点模拟不等于实体手机双拇指、真实系统后台或移动GPU性能验收。主控的人工试玩、失败与最后生产检查单独记录，不把状态反馈自动测试称为人工通关。

生产包仅在显式 `?qa=1` 下提供 `__ROADSTER_READONLY__.getState()`，返回脱离游戏对象的深拷贝；没有推进时间、改位置/速度/气压、复位或完成接口。普通生产入口没有该接口，开发推进工具仍只在开发模式存在。生产原生记录保存实际加载的打包入口名和规则/资产散列，避免把开发版结果冒称生产包检查。

首轮原生回程在回接处短暂离地，按失败保留。主控独立确认原14片中有4片违反凸性约定，并将其替换为真实宽回车区；153块共享路面、护栏、补气和恢复点保持不变。修复路径与资产对比见主控维护的 `COASTAL_INTERCHANGE.md` 和 `coastal-recovery-geometry-fix.json`。新增实际资产凸性及回程接缝足迹回归测试，不通过放宽inside或虚拟碰撞面掩盖缺陷。

两个手机尺寸均验证了后斜拉制动、侧修与抬升同时成立。Headless环境中新建标签或最小化测试窗口没有产生失焦/隐藏事件，已将这一环境限制单独记录；合成blur只证明释放接线，不作为真实系统后台测试通过。

最终源码清单、生产包、测试数和通过/未验证范围以本轮最终验证与冻结文件为准。原始QA JSON和截图仍受既有Git忽略规则影响，应随冻结清单检查实际文件。
