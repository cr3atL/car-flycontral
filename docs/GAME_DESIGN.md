# 飞行汽车特技挑战游戏设计文档

本游戏是一款面向手机横屏与 PC 的单人 3D 飞行汽车特技驾驶游戏，使用 Babylon.js。玩家在 90 秒内驾驶跑车，通过起飞越过障碍，在空中组合特技，并以安全落地结算分数。

设计重点是有车辆重量感的爽快操作、两拇指可完成的手机控制，以及随连击升级的得分反馈。默认第三人称，完整版本支持第一人称。

版本为 v0.1，整理日期为 2026 年 10 月 20 日。玩法方向已经确定；文中的速度、时间、能量、分数阈值和角度均为首轮调校起点。第一版原型范围与完整方案的差异见第一版原型章节。当前交付为设计文档，尚未进行实现或试玩验证。

## 游戏定位

| 项目 | 设计 |
| --- | --- |
| 暂用项目名称 | 飞行汽车特技挑战 |
| 类型 | 3D 驾驶与飞行特技模拟，偏爽快操作 |
| 平台 | 手机横屏与 PC |
| 人数 | 单人 |
| 开发框架 | Babylon.js |
| 正常单局时长 | 90 秒，实际游戏计时不超过两分钟 |
| 主要目标 | 利用飞行越过地面障碍，争取更高得分 |
| 核心技巧 | 起飞时机、推进时长、空中路线、动作组合、落地姿态 |
| 默认视角 | 第三人称追尾视角 |
| 成长方式 | 通过重复挑战提高操作水平、成绩和评级 |

汽车设计参考 Roadster 2 带来的低矮电动跑车印象，飞行系统为游戏内科幻设定，性能参数由玩法决定。首版采用原创车辆造型。

体验应同时满足四个条件：新手能快速完成起飞与落地；车辆具有惯性和重量；高手可以组合特技追求高分；失误后能快速恢复或重开。

## 单局流程

主菜单选择开始挑战，进入赛道与简短倒计时，开始 90 秒驾驶。倒计时、暂停和结算展示不计入实际驾驶时间。

正常流程是观察障碍、选择起飞时机、推进飞行、执行动作、调整姿态、落地结算、地面恢复能量，再进入下一组挑战。

汽车自动向前加速至当前阶段的巡航速度。首版由玩家控制转向、推进和特技；手动油门与刹车留待后续验证，避免手机初期操作过重。

主要地面障碍覆盖道路有效宽度，或阻断地面路线。横向转向用于选择空中通道、奖励环和落点，飞行始终是主要避障手段。

### 结束条件

- 90 秒结束，立即停止本局新增计分，进入结算。
- 两次自动修复机会用尽后，再次撞毁则提前结束。
- 玩家可以在暂停界面选择重新开始或返回主菜单。

到时仍未落地的待结算特技分不入账。最后八秒提供安全收尾区域和落地提示，帮助玩家提前完成结算。已在时限内完成落地判定的分数正常入账，动画未播放完不影响结果。

### 修复与容错

每局提供两次自动修复机会，第三次撞毁结束。撞毁包括翻覆、严重碰撞和掉出有效道路。

撞毁后约一秒恢复至前方安全落地区，计时继续，当前空中连击清零，已入账总分保留。恢复能量和前方安全距离应足够应对下一组普通路线，期间暂停插入新障碍。

第一道教学软质路障不消耗修复机会，碰撞后仅短暂减速；后续正式障碍按正常规则处理。

## 操作与视角

### 手机操作

横屏，以两拇指完成核心玩法。

| 输入 | 地面效果 | 空中效果 |
| --- | --- | --- |
| 左侧方向区左右拖动 | 控制转向 | 调整横向飞行路线 |
| 推进键短按 | 向上弹射起飞 | 消耗能量补充一次向上推力 |
| 持续按住推进键 | 起飞并持续推进 | 持续消耗能量，延缓下落或继续爬升 |
| 空中特技区上滑 | 无 | 后空翻 |
| 空中特技区下滑 | 无 | 前空翻 |
| 空中特技区左滑或右滑 | 无 | 对应方向的侧滚 |

特技区位于推进键上方，仅在空中明显显示。推进键与特技区是独立区域；玩家起飞后松开推进，右手即可转到特技区，左手继续调整方向。

一次有效滑动触发一次完整动作。最多缓存一个后续动作，连续滑动不能无限排队。手势方向以起始触点和明确的位移为准，轻微抖动不触发动作。

### PC 默认映射

| 按键 | 功能 |
| --- | --- |
| A 和 D 或左右方向键 | 地面转向与空中横向调整 |
| 空格短按或长按 | 弹射起飞与持续推进 |
| W | 后空翻 |
| S | 前空翻 |
| Q 和 E | 左侧滚与右侧滚 |
| Esc | 暂停或关闭暂停界面 |

PC 与手机共享物理和计分规则。PC 自由姿态操作留到后续版本；第一版采用相同的辅助特技系统。

### 镜头规则

第三人称镜头略低并保留前方视野，起飞时适度拉远，展示障碍与落点。镜头随速度平缓变化视野宽度，落地给予短促冲击。

镜头保持地平线稳定，不随车身翻转。地面提供预计落点投影，接近落地时增强提示。

完整版本提供第一人称切换，并沿用相同 HUD 信息结构。第一版原型先验证第三人称。

## 驾驶与飞行

### 地面驾驶

自动巡航保留加速过程、转向惯性和横向回稳，避免瞬间改变路线。转向幅度随速度调整，手感以手机可控为优先。

加速时车尾轻沉，转向时产生轻微车身侧倾，经过桥缝和落地时产生悬挂反馈。视觉动作不能影响玩家判断真实碰撞位置。

### 空中运动

松开推进后，汽车保留前进惯性并沿抛物线下落。空中横向调整有一定响应延迟，保持重量感；特技期间仍可调整路线。

| 参数 | 初始目标 |
| --- | --- |
| 普通弹射滞空 | 约 1.5 至 2 秒 |
| 持续推进后的典型滞空 | 约 3 至 4 秒 |
| 满能量持续推进能力 | 约 2.5 秒 |
| 地面正常行驶充满能量 | 约 4 秒 |
| 普通弹射内的动作容量 | 至少一个基础动作，并留出回正时间 |

弹射、补推和持续推进共享能量，短按不得成为无消耗的额外推力。具体能耗比例在原型中调校。

地面行驶恢复能量，空中不自然恢复。精准落地额外恢复少量能量，暂定最大容量的 10%。能量耗尽只停止提供喷气推力，玩家仍可调整路线并下落。

### 特技与辅助

系统辅助完成玩家发起的旋转，允许侧滚、前后空翻和连续组合。左右侧滚属于同一计分动作类别，前空翻和后空翻分别属于不同类别。

动作完成一整圈后才计分。未完成的翻转不获得该动作分数。已经完成的动作只有落地成功后才最终入账。

预计距落地约 0.6 秒时，若没有正在执行的特技，系统逐渐回正车轮方向并对齐行驶方向。已开始的动作继续执行，玩家仍可主动发起新动作，但会出现橙色低空提示。

辅助回正默认开启，可以关闭。关闭辅助不额外加分。自由度主要来自连续动作与路线组合，完整自由姿态控制后续再扩展。

## 落地规则

落地同时检查车身相对落地面的姿态误差、沿落地面法线方向的接近速度，以及首次有效接触部位。以下速度阈值在平路上即为向下速度。

所有条件同时满足才属于对应等级；有一项更差则按更差等级处理。车顶先触地直接判为翻覆。

| 等级 | 姿态误差上限 | 接近速度上限 | 得分与车辆反馈 |
| --- | --- | --- | --- |
| 精准落地 | 15 度 | 6 米每秒 | 特技分乘 1.2，恢复少量能量，保持行驶节奏 |
| 稳定落地 | 35 度 | 10 米每秒 | 特技分乘 1.0，正常行驶 |
| 重落地 | 65 度 | 14 米每秒 | 特技分乘 0.5，短暂减速，不消耗修复机会 |
| 翻覆或撞毁 | 超出重落地条件，或车顶先触地 | 超出重落地条件 | 当前待结算分清零，消耗修复机会 |

例如姿态误差 10 度但接近速度为 12 米每秒，判为重落地。

落地等级在一次稳定有效接地事件中确定；悬挂回弹、轮胎接触抖动和连续碰地不能重复结算。相同动作链在入账或撞毁后结束。

精准落地强调干脆的接地、悬挂压缩和回弹；重落地强调沉重声音、尘土与明显顿挫。

## 计分规则

### 分数构成

最终总分等于已完成障碍得分与已入账特技分之和。生存时间、剩余修复次数和剩余能量仅作统计，首版不额外换算分数。

越过一组主要障碍立即获得 100 分，每组一次。动作、穿环和擦障计入当前飞行的待结算特技分，落地时统一入账。

| 行为 | 基础分 | 判定 |
| --- | --- | --- |
| 越过一组障碍 | 100 | 通过组末检查区域且仍处于有效驾驶状态 |
| 完整侧滚 | 200 | 完成对应方向的一整圈 |
| 完整前空翻 | 250 | 完成一整圈 |
| 完整后空翻 | 250 | 完成一整圈 |
| 穿过奖励环 | 150 | 车身通过环的有效区域，同一环一次 |
| 擦过障碍 | 100 | 近距离经过且未碰撞，越过后确认，同一障碍一次 |

首版不按更高车速直接增加分数。速度通过增加操作压力与影响飞行路线参与玩法。

### 重复动作衰减

同一飞行中，相同动作类别首次按基础分的 100% 计算，第二次 50%，第三次及以后 25%。

左右侧滚共享重复计数，防止来回侧滚规避衰减。前空翻与后空翻各自计数。奖励环和擦障按各自对象限次，不适用翻转重复衰减。

### 组合倍率

第一种计分行为出现时为乘 1.0，每增加一种不同计分行为，倍率增加 0.25，最高乘 2.0。可计入类别为侧滚、前空翻、后空翻、穿环和擦障。

重复相同类别不增加倍率。落地等级不计入组合类别，其作用是最终落地系数。障碍通过分独立计入总分，不参与组合倍率。

当前待结算分等于本次飞行累计的有效基础分乘组合倍率。新增类别时，倍率作用于整套动作的累计基础分。

### 落地入账

本次特技入账分等于有效基础分总和乘组合倍率乘落地系数。保留计算精度，最终入账时四舍五入为整数。显示动画不改变计算结果。

例如侧滚 200 分、后空翻 250 分、穿环 150 分，共三种行为，组合倍率乘 1.5。空中待结算分为 900，精准落地后获得 1080 分。对应的障碍通过分另行入账。

撞毁会清除本套待结算分，已入账分保持。浮层因超时隐藏不会清除待结算分。

## 九十秒关卡

### 总体节奏

| 时间 | 体验目标 | 新增要求 |
| --- | --- | --- |
| 0 至 10 秒 | 完成首次起飞与落地 | 单一低障碍，只教推进 |
| 10 至 28 秒 | 认识特技与持续推进 | 简单动作、跨越连续低墙 |
| 28 至 46 秒 | 控制高度与落点 | 横梁限制、断裂道路 |
| 46 至 64 秒 | 判断动态开口 | 升降闸门、横向奖励路线 |
| 64 至 82 秒 | 组合已学会的技巧 | 距离与高度综合判断 |
| 82 至 90 秒 | 最后一次表演与收尾 | 安全直道、奖励环、落地提示 |

首轮使用固定主路线，便于玩家通过重玩进步。奖励环位置、闸门运动方向和精准落地区位置可在后续版本变化。

巡航速度初始按约 140、165、185 千米每小时三档探索，阶段间在安全直道平缓过渡。实际速度需结合场景比例、可见距离与手机反应时间调校。

### 九组主要障碍

下表为完整目标关卡的名义遭遇时间。时间用于编排体验，实际遭遇由车速、位置和可用飞行距离校准。

| 遭遇时间 | 障碍组合 | 必须掌握 | 可选奖励 |
| --- | --- | --- | --- |
| 第 6 秒 | 低矮软质路障 | 短按起飞 | 首次成功反馈，无额外教学加分 |
| 第 14 秒 | 低墙与宽阔落地区 | 起飞并安全落地 | 宽奖励环与一次特技 |
| 第 23 秒 | 两道间距较近的低墙 | 持续推进越过两墙 | 飞行中翻转 |
| 第 32 秒 | 地面墙与上方横梁 | 控制高度 | 侧边擦障路线 |
| 第 41 秒 | 断裂路面与宽落地平台 | 控制距离与回正 | 精准落地区 |
| 第 50 秒 | 低墙与缓慢升降闸门 | 判断动态开口 | 开口中央奖励环 |
| 第 59 秒 | 两道低墙与侧向奖励路线 | 空中横向调整 | 偏左或偏右的奖励通道 |
| 第 68 秒 | 短断路与高度限制通道 | 同时控制距离和高度 | 入通道前完成翻转 |
| 第 77 秒 | 低墙与旋转门及落地平台 | 综合运用已有技巧 | 窄奖励开口 |

旋转门保留宽阔基础通道，旋转结构主要影响高分路线。第一版原型将旋转门替换为已学过的升降闸门，避免增加独立障碍系统。

### 前十秒引导

0 至 2 秒展示自动加速和转向；2 至 4 秒提示推进键与起飞引导带；4 至 6 秒提示按推进飞越路障；6 至 10 秒展示落地与能量恢复。

第一次成功腾空后，再提示空中滑动。若首次起飞失败，下一组继续提供起飞指引，不提前叠加特技教学。

### 障碍编排约束

- 普通障碍提前约 3 秒可清晰识别，动态和组合障碍提前约 4 秒。
- 多数障碍组遭遇间隔约 8 至 10 秒，每组飞行后保留约 4 秒地面恢复。
- 强制路线按普通操作能耗设计并留余量，奖励路线允许更高消耗。
- 新机制先单独出现，再与旧机制组合；同组最多叠加两个强制判断。
- 动态开口有明确运动规律，不能在玩家进入后突然变成不可通过状态。
- 减速或修复后，根据实际位置和能量恢复安排后续遭遇，不为追赶名义时间压缩安全间隔；必要时略过未到达的后续组。
- 所有强制路线有清晰落点，不能让上层桥面或装饰遮挡关键障碍。

### 最后八秒

82 秒后不新增强制障碍，进入开阔直道。约 84 秒提示最后一次特技，87 秒提示准备落地，正常奖励路线在约 88 秒完成接地。

奖励路线是可选项。最后十秒的时间提醒和落地提示清楚说明收尾节奏，90 秒结束时不额外延长本局。

## 特技浮层与描述词

### 信息结构

浮层位于画面中间偏右，避开前方道路、车身及手机操作区。上方为档位描述词，下方为最大字号的本次待结算分与组合倍率，再下方为最多四条动作记录。

动作记录显示有效基础分；大数字显示乘组合倍率后的待结算分，并标注落地入账。例如基础分合计 600、倍率乘 1.5 时，大数字为 900。精准落地后改为最终 1080，明确展示落地系数，避免重复相乘的误解。

新动作完成后，记录从下方轻移并淡入，旧记录向上让位，超过四条时最旧记录淡出。动画淡入约 0.15 秒，随后约 0.15 秒完成弹动。主分数约 0.2 秒内更新到目标数值。

同一瞬间触发多个奖励可相隔约 0.1 秒依次展示，实际计分立即完成，动画不影响时限判定。

### 分数档位

档位按本次待结算或最终结算的连击分判定，不使用整局累计分。没有得分时不显示零分浮层。

| 本次连击分 | 颜色 | 描述词 | 主要效果 |
| --- | --- | --- | --- |
| 0 至 299 | 白色 | 漂亮 | 数字轻弹，少量亮点 |
| 300 至 699 | 电光青 | 精彩的 | 发光描边、青色火花、短光尾 |
| 700 至 1199 | 紫色 | 惊人的 | 星芒、细碎电弧、动作连线 |
| 1200 至 1999 | 金色 | 不可思议的 | 高光扫过、金色粒子与扩散光环 |
| 2000 及以上 | RGB 炫彩 | 不可能的 | 流动彩色数字、环绕光带和彩色粒子 |

主分数实时变色，新动作记录使用出现时对应的档位颜色，旧记录保留原色。描述词跨档时明显出现一次，之后缩回主分数上方。

单条记录可使用连续侧滚、贴身飞越、精准落地等实际动作短评。档位描述词表达精彩程度，动作记录说明分数来源。

### 两秒隐藏规则

最后一次实际得分事件刷新显示计时。0 至 1.7 秒保持显示，1.7 至 2.0 秒整体轻移淡出，第 2 秒完全隐藏。

淡出期间新增得分立即恢复，重新计时。浮层隐藏只改变显示，空中待结算分、动作类别与重复次数仍然保留。

落地结算属于新的展示事件，重新显示两秒；撞毁则切换为连击中断及本次未入账提示。顶部已入账总分常驻显示。

暂停时冻结提示计时。附属粒子应在对应两秒显示窗口结束前散去，避免浮层消失后仍有悬空特效。

## 粒子声音与震动

### 得分反馈顺序

新增动作记录时，局部粒子迸出，并以短光线汇向连击数字；到达时触发数字弹动和得分音。

跨档时叠加数字放大、扩散光环、对应颜色粒子和短音效。同一档位的升级大特效在每套连击中仅触发一次，后续得分维持该档的小反馈。

RGB 档数字采用约 1.5 秒一轮的流动渐变，不使用快速整屏闪烁。车尾短暂显示彩色能量尾迹，新增得分刷新持续时间，停止得分两秒内收束。

连续得分的提示音逐步升高，跨档使用短和弦，落地入账使用清晰收尾音。密集声音合并并限制叠加数量。

### 落地反馈顺序

精准落地先表现轮胎接触、悬挂压缩、尘雾和短气浪，再显示落地系数与最终分数；随后粒子飞向顶部总分，触发总分增长、入账音和一次短震动。

金色和 RGB 精准落地增加一道贴地能量环。重落地采用更沉的接地声、尘土与车身顿挫，数值清楚显示乘 0.5。

撞毁以待结算数字碎散和连击中断提示反馈，保留已入账成绩。

### 音乐与环境声

电驱加速声、轮胎声、风噪、桥缝声与推进喷气声共同建立速度感。通过桥下或有顶通道时，环境声有短暂变化。

背景音乐支持 90 秒由舒展到紧张、再收尾的节奏，音量给障碍提示和得分音留出空间。

手机震动默认提供轻量反馈，并可关闭。震动不可用时，视觉与声音仍能完整表达操作结果。

### 特效可读性

粒子集中在分数附近、车尾和接地处，前方障碍与落点保持清楚。强爆发短促，持续发光面积受控。

低画质减少粒子数量、光晕范围与附属光带，保留数字弹动、档位颜色、跨档反馈、RGB 变化和落地入账。

## 美术与车辆

### 总体风格

采用现代城市公路、略带未来感的原创跑车、适度风格化的写实画面。体积、材质与道路尺度有真实感，装饰细节适当简化，重点放在车辆、障碍与速度反馈。

首图采用晴朗傍晚光照，暖色阳光配合冷色阴影。远景降低饱和度，近处道路和障碍保持明确的明暗层级。雨夜与复杂天气后续扩展。

### 车辆造型

低趴宽体、短前悬、紧凑座舱、流线车头与饱满后轮拱。车头为低矮楔形轮廓配细长灯组，车身采用连续曲面与少量切线。

车尾重点制作宽轮距、贯穿尾灯、后部喷口和可辨认的飞行结构。侧裙与尾部喷口在推进时展开或调整方向，小型空气制动板随动作变化。底盘有必要的结构和喷口细节，服务翻转展示。

首台车使用深红金属车漆、黑色玻璃车顶、深灰轮毂和少量冷白灯光。普通喷气短促有力，RGB 尾迹仅在高分状态短暂出现。

### 视觉识别

- 道路以灰色为主，远景建筑降低饱和度。
- 危险结构结合黄黑条纹、实体边界与警示灯，不能仅靠颜色辨识。
- 可通过区域有明确开口与方向箭头。
- 奖励环使用青色光效，与实体危险结构区分。
- 高饱和紫色、金色和 RGB 主要留给得分反馈。
- 每类障碍在地面与空中均有可识别轮廓。

### 速度表现

路面标线、护栏接缝、路灯和桥柱形成连续掠过节奏。近景提供速度，远景提供尺度。

高速时屏幕边缘可出现少量气流线，中央视野保持清楚。镜头视野平缓变化，落地震动短促，空中维持稳定地平线。

## 赛道场景

道路层次形成复杂路况，当前可驾驶主路线始终明确。场景分为行驶区、道路两侧近景和远景天际线，分别承担玩法辨识、速度反馈和空间氛围。

| 时间 | 场景 | 玩法关系 |
| --- | --- | --- |
| 0 至 28 秒 | 开阔城市高架 | 干净路面与大面积天空，便于学习 |
| 28 至 46 秒 | 立交施工区 | 桥梁横跨、断裂桥面，对应高度和落点 |
| 46 至 64 秒 | 港区运输通道 | 货柜、吊机与机械框架，对应动态闸门 |
| 64 至 82 秒 | 临海跨桥施工段 | 开阔轮廓展示组合障碍和高难飞跃 |
| 82 至 90 秒 | 滨海直道 | 终点标识、天际线与最后表演 |

低墙包装为施工隔离结构；上方横梁来自桥体或施工框架；升降闸门采用运输通道机械结构；旋转门属于港区特技设施。

奖励路线提供更窄的环、偏移落点或擦障机会，普通通关路线保持宽阔。装饰性匝道与远处交通不能误导玩家以为可驶入。

首版以模块化高架、桥柱、隔离设施、简化楼群、货柜和海面建立方向，不要求所有分区都有独立精细资产。

## 主菜单与设置

界面采用现代跑车仪表与赛事转播信息的视觉语言：深灰半透明面板、大数字、少量细线与强调色。危险与操作信息优先，高强度颜色留给得分。

主菜单背景为车辆停在高架观景区的展示画面，缓慢镜头展示车身、港口和天际线。

| 位置 | 内容 |
| --- | --- |
| 左上 | 项目标识与名称 |
| 左侧中央 | 九十秒飞行挑战及一句玩法说明 |
| 左下 | 个人最佳成绩与历史最高评级 |
| 右下 | 开始挑战主按钮，操作说明与设置次按钮 |
| 右上 | 声音快捷开关 |

首次进入提示包含驾驶引导。开始后镜头转到追尾视角，再进入倒计时。

设置包含音乐、音效、震动、画质与辅助回正。完整版本加入视角选择；第一版仅提供第三人称。后续支持手机操作区大小和透明度调整。

操作说明用起飞、特技与落地三个步骤解释核心循环。个人最佳与设置首版保存在本机，不需要账号或联网服务。

## 游戏 HUD 与手机界面

| 区域 | 内容 | 显示原则 |
| --- | --- | --- |
| 左上 | 已入账总分、当前评级及下一档进度 | 总分常驻，仅入账时增长 |
| 顶部中央 | 剩余时间与局内进度条 | 最后十秒转暖色，避免持续闪烁 |
| 右上 | 暂停按钮 | 与得分浮层分离 |
| 中间偏右 | 连击分、倍率、描述词与四条动作记录 | 两秒无得分后消失 |
| 左下方向区上方 | 速度 | 大数字与小单位 |
| 下方中央 | 推进能量与剩余修复机会 | 能量不足有明确提示 |
| 车辆上方附近 | 当前最重要的路况或落地提醒 | 同时只保留一条主要提醒 |

评级进度只按已入账总分推进，空中待结算分不能提前改变常驻评级。第一人称模式后续加入视角快捷切换按钮。

手机方向区默认低透明圆盘，触摸后显示摇杆；推进键为最大操作按钮，按住时外圈反馈能量消耗；空中特技区位于推进键上方。

触控区避开屏幕安全边缘和系统手势区，支持左右手同时输入。横屏 16 比 9 和更宽手机比例下，HUD、连击浮层和触控区不能互相覆盖。

按键通过亮度与形变明确反馈按下状态。首次飞行显示手势箭头，熟悉后收起；关闭教学后仍可在操作说明中查看。

### 暂停与中断

暂停界面提供继续挑战、重新开始、操作说明和返回主菜单。暂停时冻结物理、局内时钟、能量恢复与得分提示计时。

恢复前给予简短倒计时，期间维持暂停。手机切到后台、窗口失焦等中断按暂停处理，恢复时清除遗留按键和触摸状态。

## 结算与评级

### 结算布局

背景停留在终点或本局结束位置的车辆画面，并适当压暗。左侧展示大号评级徽章、评价文案和最终总分，右侧展示分项统计，底部提供再来一局与返回主菜单。

统计包括障碍得分、已入账特技分、最高单次连击、精准落地次数和有效驾驶时长。最高单次连击只统计已成功入账的动作链。

刷新纪录显示个人最佳。正常完成标注九十秒挑战完成；提前结束标注挑战中断及坚持时长。

### 评级阈值

| 评级 | 最终总分 | 名称 | 评价 |
| --- | --- | --- | --- |
| C | 0 至 1999 | 初次升空 | 每一次起飞，都在靠近下一次突破。 |
| B | 2000 至 3999 | 渐入佳境 | 你已经找到飞行与落地的节奏。 |
| A | 4000 至 6499 | 空中好手 | 漂亮的动作，也有可靠的落地。 |
| S | 6500 至 8999 | 特技大师 | 速度、姿态和时机尽在掌握。 |
| SS | 9000 至 11999 | 极限驾驶者 | 一次接一次，把高难动作变成连击。 |
| SSS | 12000 及以上 | 不可能的驾驶 | 这趟飞行，值得再看一遍。 |

完整存活不额外限制评级，提前结束也按已入账分数使用同一标准。评分不重复惩罚撞毁。

这些阈值必须结合首版关卡可获得分数校验，SSS 应在熟练玩家的合法操作下可达成，不能依赖重复刷分或异常判定。

### 揭晓反馈

约两秒完成总分增长、评级逐档亮起和最终徽章落定。按钮始终可响应，玩家可跳过动画。

C 至 A 使用简短光效；S 加金色扫光；SS 增加粒子环；SSS 使用独立炫彩徽章、一次彩色爆发与完整收尾音。

根据本局表现给出一句具体建议，例如尝试组合侧滚和空翻、提前回正提高精准落地次数。

## 性能与制作约束

### 运行目标

中端参考手机以稳定 60 帧为目标，较低配置提供稳定 30 帧档位；PC 在约定参考设备和分辨率下以稳定 60 帧为目标。参考机型、系统、浏览器与分辨率在原型实现前选定并记录，当前不把目标视为实测承诺。

性能评价应覆盖完整 90 秒、多组障碍、最高档粒子、精准落地与结算。手机需要连续运行多局，观察发热后的帧率和触控响应。

### 美术与场景预算原则

将精细度优先分配给玩家车辆和当前障碍。远处楼群以简化轮廓建立天际线，路灯、护栏、桥柱与货柜使用重复模块。

光照、车漆、玻璃和海面采用成本可控的表现。精细动态阴影集中在车辆附近，远处环境优先使用预先制作的明暗关系。

赛道分段维护显示范围与物件数量，已离开区域不持续累积。高分粒子、尘雾和光带有明确数量与寿命上限。

### 玩法稳定性

快速行驶中不能穿透障碍、漏判奖励或重复结算。暂停、修复、重开与切后台恢复必须清理上一状态的遗留输入及特效。

图形质量变化只调整表现复杂度，物理、评分、障碍时机和可通行路线保持一致。

不把重度模糊、复杂天气和大面积实时反光作为速度感成立的前提。

五档得分反馈都需要有可辨差异，RGB 与落地入账必须实现；复杂电弧、精细材质和高级粒子形态允许用简化表现验证。

推进机构可先通过喷口、简单展开动作和短喷气表现。精细机械结构与车辆内饰不在首版范围内。

本机最佳成绩不等同于在线排行榜。首版不增加账号、多人、车辆养成、商业化、开放城市、随机赛道和天气系统。

## 原型验收标准

以下为后续实现后的验收目标，目前尚未执行。

### 新手与操作

- 首次玩家能在前十秒理解推进键；首道障碍失误不损失修复机会。
- 组织至少五名首次接触的玩家体验，目标是至少四名在两次尝试内完成起飞、一次特技与稳定落地。
- 手机两拇指可完成移动、推进和特技切换，没有必须第三指参与的步骤。
- 连续动作只缓存一个，取消触摸、暂停与切后台后无残留推进或持续转向。
- 镜头在翻滚中保持稳定，落点提示能够帮助判断着地点。

### 玩法与关卡

- 不做特技也能通过全部强制路线，奖励路线提供额外挑战。
- 普通起飞能完成一个基础动作并留出回正时间，持续推进可支持组合动作。
- 各强制路线在预设能量条件下可通过，正常完成上一组后有足够恢复时间。
- 第一组教学、九组节奏和最后八秒收尾均可完整体验。
- 减速与修复后不会为追赶时间生成必撞障碍。
- 第三次正式撞毁提前结束，第一道软路障和重落地不错误扣除修复机会。

### 计分与边界

- 侧滚、后空翻、穿环并精准落地的示例准确获得 1080 特技分，障碍分另计。
- 同类翻转按 100%、50%、25% 衰减，左右侧滚不能绕过衰减。
- 第一种行为倍率为乘 1.0，五种行为达到乘 2.0，重复类别不增加倍率。
- 奖励环、擦障、障碍通过与落地不能被同一对象或一次接触反复触发。
- 撞毁只丢当前待结算分，暂停不推进计时，90 秒后不能继续新增得分。
- 等级边界 300、700、1200、2000，以及结算边界 2000、4000、6500、9000、12000 均准确切档。
- 校验首版合法动作和路线的可得分范围，确认 RGB 与 SSS 可达成；必要时调整奖励布局或阈值。

### 显示与反馈

- 最后一次得分 1.7 秒后开始淡出，2 秒时浮层与附属粒子消失。
- 隐藏不清空连击；再次得分或落地结算能重新显示。
- 动作列表最多四条，描述词、主分数、倍率和基础分含义清楚。
- 金色和 RGB 可明显区分于低档反馈，前方障碍和落点始终可读。
- 落地入账动画、顶部总分、结算总分与个人最佳一致。
- 结算可跳过动画并快速重开。

### 性能与兼容

在记录好的参考设备、浏览器、分辨率与画质档下测量整局。60 帧档以约 16.7 毫秒帧时间为目标，30 帧档以约 33.3 毫秒为目标，记录明显卡顿与持续掉帧。

重点覆盖 RGB 粒子、精准落地、动态闸门和结算转场。连续运行多局后，场景物件与特效数量不应持续累积，触控与画面响应保持可用。

验证手机安全区、16 比 9 与更宽横屏比例、PC 窗口尺寸变化。画质变化不改变玩法结果。

## 待调校参数与扩展边界

| 参数 | 初始值或方向 | 验证重点 |
| --- | --- | --- |
| 巡航速度 | 约 140、165、185 千米每小时 | 手机反应时间、速度感与场景比例 |
| 普通滞空 | 约 1.5 至 2 秒 | 一次动作与回正是否充足 |
| 推进滞空 | 约 3 至 4 秒 | 多动作与跨障碍的可行性 |
| 持续推进能量 | 约 2.5 秒 | 短按、长按与组合消耗的平衡 |
| 地面充满时间 | 约 4 秒 | 障碍之间是否能形成恢复节奏 |
| 精准落地回能 | 最大容量的 10% | 奖励技巧但不形成无限续航 |
| 回正窗口 | 预计落地前约 0.6 秒 | 手机容错与低空特技风险 |
| 落地阈值 | 15、35、65 度及 6、10、14 米每秒 | 反馈与玩家感知是否一致 |
| 遭遇间隔 | 多数约 8 至 10 秒 | 飞行、落地、恢复与预判时间 |
| 特技炫彩阈值 | 单次连击 2000 分 | 高难组合能达到且有稀缺感 |
| SSS 阈值 | 全局 12000 分 | 熟练玩家可达成，普通通关有成长空间 |

实现前还需选择参考手机与 PC、确定场景比例和飞行参数、明确擦障有效距离及低空提示范围。上述属于原型调校工作，不改变已确定的玩法方向。

首版完成后，以新手成功率、重玩意愿、各档评分分布、撞毁原因和设备表现决定后续投入。优先改善操作与关卡可读性，再扩充车辆、场景和玩法数量。
