# 飞行特技与新手引导优化设计

日期：2026年10月21日。状态：用户已在设计文档交付后授权按新版方案进行一次迭代，当前进入开发与验收阶段。本文是本轮实现准则；条目是否实现及通过，以开发记录和主控验收为准。

面向PC与手机横屏的Babylon.js原型。核心体验是沉重汽车被喷气推离路面，保持向前冲的惯性；玩家决定推进时长、表演动作与落点。通过完整特技和空中补给恢复主气压，允许主动用完主气压，再由独立着陆缓冲保障正常接地。

## 优化目标与规则优先级

当前反馈集中在特技形态难以理解、飞行与收势不连贯，以及玩家不知道眼前应做什么。下一轮先改善一次起飞、一次侧滚和一次落地，再把它们组织成可独立上手的前20秒体验。

本文的飞行、输入、气压、动作衔接、着陆辅助和教学规则，优先于第二轮[HANDLING_REWORK.md](HANDLING_REWORK.md)及现有实现中的对应旧约定。[GAME_DESIGN.md](GAME_DESIGN.md)保留整体定位，[SCORE_FEEL.md](SCORE_FEEL.md)保留计分公式和声画语义，[CHALLENGE_DESIGN.md](CHALLENGE_DESIGN.md)保留90秒流程与实际障碍来源，[ART_DIRECTION.md](ART_DIRECTION.md)保留车辆与场景美术方向。

旧物理轨迹、点按Q+W即获2430的操作路径和九组起飞距离是历史证据。下一轮允许并需要改变物理参数与动作调度，应重录新路线，不再要求旧物理哈希不变。现有资产、得分真实性、暂停规则和移动端操作能力仍需回归。

| 项目 | 当前版本约定 | 新规则 |
| --- | --- | --- |
| 持续推进 | 追踪固定支撑高度 | 持续施力，无固定飞行高度封顶 |
| 基础侧滚 | 按住可连续旋转 | 一次明确输入完成一圈，额外输入才接续 |
| 双动作 | 两轴同时转动 | 顺序衔接，最多缓存下一招 |
| 空中主气压 | 消耗后不恢复 | 完整特技及气压补给环可恢复，每次腾空有额度 |
| 主气压归零 | 主动稳定也失去输出 | 已付费动作完成收势，独立缓冲继续保障正常接地 |
| 前期目标 | 多种规则同时出现 | 先越障，再侧滚，再自主重复 |
| 收动作时机 | 玩家主要凭高度判断 | 按预计接地时间、动作时间及比赛剩余时间提示 |

冷气矢量推进延续游戏设定；空中补给和独立缓冲属于玩法奖励与辅助，不代表真实车辆的气体回收或工程控制系统。

## 喷气推力与向前惯性

### 推进输入

| 输入 | 车辆反应 | 费用归属 |
| --- | --- | --- |
| 地面点按推进 | 提交一次约0.45秒的完整起飞脉冲，产生清楚向上冲劲 | 一次扣除18点，覆盖整段脉冲 |
| 地面继续按住 | 起飞脉冲结束后衔接较柔和的持续推力 | 此时开始每秒16点，不与脉冲重复扣费 |
| 空中点按推进 | 提交一次弱于地面起飞的短喷，补充上升速度或减缓下降 | 一次10点 |
| 空中继续按住 | 当前短喷结束后接持续推力 | 每秒16点 |
| 松手 | 已提交短喷完成，持续推力平滑收尾 | 已付费短喷不因松手失效，持续部分停止扣费 |

持续推力不读取目标悬停高度，不在旧支撑高度附近额外衰减，也不直接钳制车高或改写速度。松手时保留上升、向前与横向惯性，随后由重力、空气阻力和有限辅助继续演化。实体顶棚仍有碰撞，不使用不可见的天空封顶。

向前运动继承地面车速，空中前向助推只作补充。抬头或侧滚不能把巡航速度整体转成突然向上蹿升，也不能让车悬停原地旋转。前20秒先通过地面加速建立速度感，再要求起飞。

升力矢量负责世界向上的支撑，姿态微喷负责转动和制动。喷口位置随车体运动，排气方向和矢量调整应与实际受力一致。镜头不跟随车辆翻滚，保留稳定地平线。

### 首轮调校目标

普通短按目标为约2.5—3秒滞空，足够舒展完成一次侧滚并留出收势；侧滚目标约1.2—1.5秒。两者应联合调校，不能分别达标却没有落地余量。

持续推进应明显比短按飞得更高、更远，能够自然越过旧支撑高度。最高高度由初速度、推力曲线、气压和阻力产生，不预设一个新的最大高度数值。持续推进的力值、空中短喷时长、反应曲线与阻尼属于下一轮需要记录和试玩校准的参数，不是已验证结果。

## 主气压与动作预留

主气压显示范围为0—100点。HUD继续使用一条主气压表，不把动作预算或独立缓冲伪装成主气压回充。

| 行为 | 首轮数值起点 |
| --- | ---: |
| 地面起飞脉冲 | 18点 |
| 脉冲后持续推进 | 16点每秒 |
| 空中短喷 | 10点 |
| 基础侧滚 | 12点每次 |
| 持续左右微调 | 按输入强度消耗，最多3点每秒 |
| 地面回充 | 25点每秒 |

这些数值是已讨论采用的首轮调校起点；后续如调整，应成组更新参数表、示范路线与验收记录。费用按实际模拟时间计算，不依赖显示帧率。低气压不提前大幅降低操控灵敏度；用尽时推力平滑结束，不制造额外冲量。

动作开始时从主气压扣除完整预算，用于该动作的加速、旋转、减速和收势。预算只属于当前动作，不可用于继续爬升；之后主气压归零，已开始的侧滚仍能完成。动作尚在队列中时不扣费，真正开始前再次检查气压与安全时间。

不足18点不能提交地面起飞，不足10点不能提交空中短喷，不足12点不能开始新的侧滚；提示原因且不扣费。不允许付费输入在气压不足时排队，等日后回充再突然触发。持续推进与横移按剩余额度结束，不允许负数或透支。

已支付的预算不转回主气压、不计入补给额度。因碰撞中断时清除未用动作预算，不产生退款或免费补气。地面只有真实支撑接触时才回充；悬挂回弹不生成新的腾空奖励周期。

## 基础侧滚与动作衔接

### 操作

| 行为 | PC | 手机 |
| --- | --- | --- |
| 左侧滚一圈 | 点按Q | 特技区明确左滑一次 |
| 右侧滚一圈 | 点按E | 特技区明确右滑一次 |
| 再接同向一圈 | 再按一次同方向键 | 再作一次明确同向滑动 |
| 接下一种动作 | 在安全窗口内再输入 | 在安全窗口内作下一次滑动 |

手机主路径是右拇指先点按推进，再移到特技区滑动，左拇指保持可用的方向操作。不要求新手同时按住推进、横移和滑特技三项。保留多触点能力，持续推进与特技可以由两个触点配合，但教学不依赖这种操作。

按住Q/E不会自动追加多圈，键盘自动重复事件不生成新动作；必须释放并重新按下。一次触控手势最多提交一次动作，含糊小幅移动不触发。地面起飞输入与紧接的侧滚可以在真实离地后接续执行，不强迫玩家多等一段无意义时间。

### 动作形态

一次侧滚依次经过起势、主体旋转和收势。微喷先加速，车身沿纵向完成清楚的一圈，再通过反向微喷减速。车头大体保持前进方向，不附带难以辨认的甩头或任意复合旋转。

允许少量受控惯性余摆，禁止通过直接设置角度或清零角速度来隐藏收势。真实完成一圈才产生完成事件，目标值、动画进度或回正到水平都不能代替实际动作计数。

### 队列和低空输入

当前动作之外最多缓存一招。已有下一招时再次输入不覆盖、不追加，给一次简短的“已接下一招”反馈，防止快速滑动变成多招失控连播。

同方向接续保持顺畅转速，但每圈仍有可读的动作节拍；反向或切换前后翻时先收住当前转动，再进入下一招。禁止两个独立姿态目标同时拉扯车体。

同帧侧滚和前后翻输入采用“侧滚先开始，另一招作为下一招”的明确顺序；旧的同时双轴旋转不再作为默认组合。手机对角滑动相应表达顺序组合，须有简短动作预告，不能继续显示成未发生的旧螺旋动作。复杂螺旋动作留待后续单独设计。

本轮必须验证侧滚接侧滚，以及侧滚接一个已有前后翻动作。前后翻基础分仍为750；其用气预算和动作时长未在讨论中冻结，开发首轮可暂以12点预算接入，须独立配置、验证并在交付参数表中标明，不把它称为已经确认的最终数值。

只有预计剩余接地时间足够完成下一招及收势，并且主气压足够时，才接受下一招。队列执行前重检条件；条件变差则清除未开始的动作，提示“准备落地”，不扣预算、不在下次起飞补做。当前已经开始的动作尽量完成收势，不在低空突然切断。

## 空中补气奖励

| 来源 | 补给请求值 | 领取时刻 |
| --- | ---: | --- |
| 本次腾空首次完成一种完整特技 | 20点 | 实际完成一圈时，不等落地 |
| 同类特技第二次完成 | 10点 | 本次实际完成时 |
| 同类特技第三次及以后完成 | 每次5点 | 本次实际完成时 |
| 气压补给环 | 30点 | 实际穿过且首次领取时 |

左右侧滚共享一个类别，不能通过左右交替重复领取首次20点；前翻、后翻沿用各自类别。半圈、往返抖动、重复越过已经计数的角度区间不补气。计分完成与补气使用同一个实际动作事件，分别更新各自账目。

每次有效腾空，所有来源实际补入主气压的累计值最多60点；地面回充不计入这个额度。达到额度后动作仍可继续、仍按原规则计分，只是不再补气。补气不提供额外分数或动作类别倍率，也不直接改变高度和速度。

实际补入值取“请求值、距100点的空位、距60点的本次腾空余额”中的最小值。满罐时实际补入0，不消耗60点余额，但本次动作的重复次数或该环的已领取状态仍被消费，不能稍后回来领取同一事件。

例如：100点起飞扣18，侧滚开始扣12，完成首次侧滚补20，忽略微调与持续推进后剩90点。若当前95点、腾空余额足够，补给环只实际补入5点，提示“气压补给 +5”。

气压补给环使用气罐图形、明确的“+30气压”标记和可辨轮廓，不仅依靠颜色区别。本轮默认是独立补给物，只补气；原可选得分环仍按450分规则运作，不自动把两种环合并或偷偷更改类别倍率。演示路线至少有一个不需要耗尽后的主动横移也能穿过的补给机会。

一次腾空最多60点，加上起飞前100点，主气压来源有限，不能无限续航；不限制特技表演次数，也不重新加入高度封顶。主气压为0时仍可能因已付费动作完成或穿过环而重新获得补给。

每次有效起飞建立独立腾空周期，真实落地结束该周期。悬挂弹跳、暂停恢复、切档、穿环边界抖动、修复过渡不得重置类别次数或补给额度。新周期必须由真实接地后的新起飞建立。

## 独立着陆缓冲与落地手感

### 保障范围

每次有效起飞自动准备一次独立着陆缓冲，不占用100点主气压，不消耗本次60点补给额度。HUD以“着陆缓冲就绪”说明它的存在，不再额外放一条需要玩家管理的气压槽。

承诺是：主气压用完本身，不会导致正常四轮接地时的重落地惩罚。车辆在安全主路、正常可达高度、可收势姿态下降时，缓冲有足够能力提前介入并完成安全接地。必须覆盖使用全部主气压及全部空中补给之后的飞行范围，不能只保证普通短跳。

车顶或侧面直接撞地、撞上墙或顶棚、驶出道路、落入缺口仍按真实碰撞处理。缓冲不会生成地面、移动车辆到安全点，或把严重碰撞算成精准落地。目标是消除因耗气导致的落地焦虑，保留路线与姿态技巧。

### 连续制动

根据下降速度、制动能力、车体接触高度及前方实际可落地路面，提前估计所需制动距离。下降越快，开始得越早，不能依赖一个固定离地高度触发，也不能等已经触地后再把接触速度改小。

缓冲只减少下落速度、收残余转动，保持向前运动，不产生重新向上爬升或悬停收益。正式进入缓冲后清除未开始的特技；本轮不支持退出缓冲重新表演。主气压足够时仍允许有限横向修正，但推进输入不把缓冲变成新的起飞。

新补给可以继续记入主气压，但不能重新武装缓冲或重开空中动作阶段。缓冲到真正接地是一段连续过程，不能反复开关刷续航。技术参数按正常可达范围配置，不把缓冲设计成可以被玩家用光、从而重现同样焦虑的第二套油量管理。

### 接地表现与评价

| 结果 | 条件与手感 |
| --- | --- |
| 精准落地 | 提前收势、姿态稳定并落在明确推荐区域；轮胎接地、悬挂压缩、短回弹、沉实确认音与入账形成同一节拍 |
| 稳定落地 | 安全接地，允许前后轮略有先后与轻微俯仰，迅速继续驾驶 |
| 重落地 | 不良姿态或外界碰撞造成异常接触；更深压缩、沉闷反馈与暂时减速，不能由单纯主气压归零触发 |

精准/稳定/重落地的现有1.2/1/0.5计分系数保留；具体姿态、接触速度、推荐区域与提前收势窗口在新物理下重新标定。主动辅助不等于每次自动精准。两秒浮层、RGB和实际落地才入账的语义保留。

每次腾空最多结算一次；弹簧回弹不重复入账、不刷新缓冲、不重置补给额度。接地不清空真实动量来制造稳感；允许悬挂吸收与受控回弹，同时迅速恢复地面转向与向前行驶。精准落地后的额外加速奖励延后，不与本轮同时引入。

## 空中左右微调

方向输入产生有限横向推力，车身有小幅、可读的侧倾，路线逐渐偏移。松手后辅助逐渐收住横向漂移，保留短暂惯性，不瞬间横移或锁死横向速度。

侧滚中仍可微调，但效力适度减小，避免路线移动与旋转互相放大。微调强度和阻尼以两拇指操作为准，与持续推进共用主气压；主气压耗尽后主动横移停止，独立缓冲照常可用。

本轮不增加自由抬头爬升、压头俯冲、空中倒车、悬停或自由航向控制。喷气汽车始终主要向前冲，侧滚负责表演，方向输入负责选择落点。

## 收势判断与HUD

提示依据预计接地时间，不单看离地高度。预测应计入当前上升/下降速度、已提交短喷、已付费动作、缓冲与真实地形，并随玩家后续输入更新；不得使用未获得的未来补给来承诺安全。

| 状态 | 展示与行为 |
| --- | --- |
| 还能接一招 | 气压足够，预计接地及本局剩余时间容得下完整下一招与收势余量；落地区青色 |
| 收动作 准备落地 | 不再满足下一招条件，提示停止追加；推荐区域变暖黄色 |
| 着陆缓冲 | 系统实际开始连续减速与收势，有对应喷流和简短声音 |

同样离地5米，正在上升与快速下降时可以给不同提示。状态应有稳定余量，避免在阈值附近来回闪变。没有可到达的有效路面时，不显示虚假的青色安全落点。

主气压为0时优先说明“气压用尽，着陆缓冲就绪”，而不是只显示危险红条。动作完成先确认动作，再显示实际补气数字，气压表同步回涨。补气使用独立小提示，不延长最后真实得分后2秒的主分卡截止，也不覆盖推进与特技区。

90秒规则继续有效。收尾提示还要比较本局剩余时间与预计接地时间，不能只在87秒固定提示。补给和缓冲不暂停或延长比赛；到时仍在空中的未入账分仍不计入总分，不自动落地或转存。

| 名义时间 | 道路与操作 | 成功条件 | 反馈 |
| --- | --- | --- | --- |
| 0—4秒 | 自动加速宽直道，近景建立速度感，可轻试左右方向 | 车速与前进方向建立，不要求主动特技 | “车辆自动前进，左右调整方向” |
| 4—8秒 | 清楚黄色起飞区，一面矮墙，墙后宽长落地区 | 按标记点按推进，飞越矮墙并安全落地 | 先“到黄色区域点按推进”，再“落地成功” |
| 8—11秒 | 安全回充直道，无额外障碍 | 真实接地、气压足够下一段 | 简短回充确认，收掉上一条提示 |
| 11—16秒 | 第二个明显起飞区、宽落地区；不用低顶或强制奖励环 | 起飞后左滑/按Q，完成侧滚，立即补20点，再落地 | “现在左滑／按Q”，完成后显示动作与补气，随后提示收势 |
| 16—20秒 | 宽直道，自主重复刚学会的动作 | 可以自行再做一次；允许只安全驾驶 | “再试一次，争取精准落地”，不再逐按钮指挥 |

第一跳只教越障，不要求侧滚；第二跳只教一个侧滚，不要求2000分、对角组合、擦障或窄环。第二段不放必须再次起飞才能越过的紧接障碍，也不把装饰横梁放入飞行通道。地面起飞区是提示标记，不伪装成有额外物理的跳台。

起飞标记按新脉冲、当时车速与墙体位置校准；落地区按自然飞行路线留宽裕空间，不直接复用旧45/70米与旧按住时长。主镜头必须同时让玩家看清起飞区、障碍与可落区域。

教学段失误快速回到当前小段的安全位置，本轮建议不扣正式修复次数；比赛计时继续，不通过隐藏停表制造20秒达标。这个教学容错是替代旧“第一墙仅一次免费纠错”的新实现约定。后续教学等待实际落地与气压恢复，晚完成时顺延后续强制遭遇，不能追赶旧时间表贴脸刷障碍。重复触发同一组目标不给额外组通过奖励。

20秒后的首个可选补给机会展示气压补给环；主路线仍可安全通过。引导不要求玩家先耗尽气压，之后提供一个明确的自由练习目标“放心用完推进，观察缓冲落地”，验证玩家是否理解系统保障。

## 下一轮开发范围

按以下顺序在同一原型中完成，前一阶段的体验问题没有解决时不扩展新动作库。

| 阶段 | 必做内容 | 阶段完成标准 |
| --- | --- | --- |
| 一 飞行与落地 | 去掉目标高度支撑，重做短喷/持续推进，主气压费用、动作预留和独立缓冲 | 自由练习里短按/按住差异明确，烧完气压也能安全正常接地 |
| 二 侧滚与补给 | 一次输入一圈，起势/主体/收势，最多下一招，顺序接续，特技补气和补给环 | 侧滚形态可读；侧滚接侧滚及侧滚接前后翻成立；补气和入账可复算 |
| 三 引导与适配 | 前20秒教学，接地预测/收势提示，PC与手机输入，现有90秒模式最小适配 | 玩家能依靠道路与提示独立完成；90秒闭环仍可玩，不强迫沿用旧九组时序 |
| 四 声画与验收 | 起飞冲劲、动作完成、补气、收势喷流与落地节拍；资源/暂停/分档回归 | 原速实际输入、原始轨迹、截图与完整测试记录可复核 |

20秒之后保留现有障碍类型与城市资产，按新飞行包络调整必要尺寸、预警和间距，证明至少一条完整90秒合法基础路线。九组全部追分路线、最终评级阈值与高级特技库的精修延后，不把本轮称作完整内容与平衡定版。

分数基础值、类别倍率、重复衰减、RGB2000门槛、落地入账和C至SSS展示保留。须用新顺序操作复现一次双类别2025待结算、精准2430，不要求旧的短按Q+W双轴路径原样成立；单侧滚600、精准720足以作为教学成功，不以2000作为新手门槛。由于补给、连招与精准条件改变得分机会，新规则使用独立最佳纪录版本并保留旧数据；评级刻度后续用新路线重新标定。

本轮不做新车辆或大规模场景重制、第一人称、联网/账号/商城、复杂螺旋与自由飞行、额外落地加速奖励。丰富档首次RGB长帧是已有未关闭问题：本轮必须回归并记录，若不能解决则保留限制，不以中位60FPS宣称全部性能通过。

## 验收标准

所有条目开工时均为待验。工程检查验证规则和边界，实际试玩验证清楚、连贯和上手程度，两类证据分别记录。

| 编号 | 检查内容 | 通过标准与证据 |
| --- | --- | --- |
| O01 | 无高度封顶 | 相同输入/气压条件下没有高度触发的额外推力抑制；真实持续推进可越过旧支撑高度，松手后自然升降，有轨迹记录 |
| O02 | 推进连续性 | 轻点能完成整段脉冲；持续按住有连续后劲；补喷不重置速度；无姿态/速度瞬移或伪造悬停 |
| O03 | 主气压费用 | 18/16每秒/10/12/最多3每秒/25每秒均可复算；脉冲与持续部分不重复扣，帧率变化费用一致，无透支 |
| O04 | 已开始动作保障 | 侧滚预扣一次；随后主气压用完仍可完成并收势；未开始队列无扣费、无预发奖励 |
| O05 | 侧滚操作 | PC点按Q/E与手机单次左右滑各完成一圈；按住不自动多圈；真实原速输入和逐步轨迹均验证 |
| O06 | 侧滚观感 | 起势、完整一圈、收势均清楚，车头方向可预判；先单招再顺序组合，没有默认双轴乱转、角度吸附或强行清零角速度 |
| O07 | 动作衔接 | 最多一个下一招，同向平滑延续、换向/换动作先收势；危险时拒绝未开始动作并提示；快速多按不会长队列补播 |
| O08 | 补气真实性 | 首次20、第二次10、以后5、补给环30按实际事件到账；左右共享侧滚类别；半圈/抖动/同环反复进入不重复补给 |
| O09 | 补给额度 | 实际入账同时受主气压100与腾空60上限约束；满罐、临界额度、主气压为0、同帧多事件都正确；弹跳不重置额度 |
| O10 | 零主气压安全接地 | 普通短跳、长按爬升、补满本次60点额度后的高飞路线，分别在上升、顶点、下降阶段耗尽主气压；正常可收势姿态落在安全主路时均不因耗气产生重落地/撞毁 |
| O11 | 缓冲边界 | 制动在接触前连续发生；不能用于爬升、刷悬停或重置空中额度；墙/顶棚/侧顶着地/缺口仍真实碰撞，不能造地面或瞬移 |
| O12 | 落地与入账 | 精准与稳定可辨，落地节拍统一，悬挂回弹只结算一次；主气压归零不自动判精准，也不自动判重落地 |
| O13 | 提示与预测 | 同高度上升/下降提示可不同；气压不足不能显示能接招；无安全路面不画安全落点；计入缓冲与比赛余时，阈值附近不频繁闪变 |
| O14 | 教学完整流程 | 正常路线约20秒完成起飞越障、侧滚补气、安全落地和一次自主尝试；等待/失败时后续提示与障碍按完成状态顺延 |
| O15 | 教学信息与可读性 | 每次一个主要目标；起飞区/落地区可见；不要求阅读操作表、听口头讲解或先做2000分；气压/动作提示不遮挡道路和触控区 |
| O16 | 新计分路径 | 实际单侧滚精准720；实际顺序双类别2025待结算/精准2430；补气不冒充得分、补给环不冒充旧450分环 |
| O17 | 暂停与状态清理 | 暂停/失焦/后台冻结模拟、预算、补气次数与缓冲；恢复继续已提交短喷和当前动作，清按住及下一招队列；重开不带旧奖励/输入/声音 |
| O18 | 90秒兼容 | 至少一条真实物理基础路线到90秒、无必撞障碍；末段高飞时动态提示收尾；未落地分不虚假入账，存储失败可继续，新旧最佳不混比 |
| O19 | 手机与性能 | 844×390及667×375横屏可完成全部核心路径，无新增按钮负担；实例/队列有界，切档/重开不增长资源；丰富/精简冷启动都含首个特技、补气、RGB与落地，记录完整帧间隔及长帧 |
| O20 | 体验验收 | 主控和用户以真实原速输入检查汽车重量、动作辨识、收势和落地；体验反馈仍怪或看不懂时，不能仅凭自动测试判完成 |

O10的工程用例应使用真实输入可达到的轨迹，并补充分离的受力/预测边界测试。不能直接修改接地速度、姿态、分数或气压，让界面显示成功来代替实际安全落地。O19区分桌面键盘、桌面触控模拟与手机真机；真机设备、持续帧率/温升未测时明确保留待验，不外推手机60FPS。

建议另外找至少3名未看操作说明的首次玩家，记录首次越障、侧滚完成、落地、误操作、读提示次数，以及能否解释“主气压用完也有缓冲”。目标至少2人仅靠游戏内引导完成教学；这是小样本体验检查，不作普遍易上手的统计保证。没有实际参与者时如实列为未完成的体验证据，不用pilot或开发者熟练操作代替。
