# 滨海立交试驾区

本轮开发依据用户确认的[概念预览](concepts/coastal-interchange-preview.png)。目标是让驾驶、短喷跨桥、抬升切线、反推落台、落地续行连贯。PC与横屏手机双拇指均需能完成。新Roadster不加入计分规则，不恢复旧自动巡航或独立三轴特技。

## 路线

世界x左右、y向上、z前进。主路y=0，海面y=-8。普通沿岸路线允许地面绕行到出口；飞行提供跨越和高架路线。

| 区段 | 位置 | 行为 |
| --- | --- | --- |
| 起步与直道 | x=0，z=0..110，宽12 | 手动加速，前30米可练刹车 |
| 断桥 | z=110..134，缺口24 | 边缘前8..12米提示短喷，目标速度80..100km/h |
| 接收道路 | x=-9..9，z=134..204，y=0 | 全面可落，留足纵向容错，落地继续开 |
| 缓S弯 | z=204..284，中心x从0平滑偏到20，宽14..18 | 转向与速度调整，提前看见检修区 |
| 检修区 | x=6..34，z=284..324，y=0 | 20..40km/h接近，抬升同时向右修正 |
| 上层入口 | x=20..40，z=338..393，y=8 | 偏右约10米，前向间隔14米，反推减速后落台 |
| 高架下坡 | x=20..40，z=393..473，y=8..0 | 保持前向速度，顺坡回到主路 |
| 出口 | x=21..39，z=473..523；完成线z=510 | 实际接地驶出完成 |

接收路和高架蓝色条带用于快速补气，整块路面均可落地。恢复路在断桥下方y=-5，左侧坡道返回起点；桥墩避开该恢复区域。沿岸道路绕过第一断口；下层路绕过高架后汇入出口。

曲线路面采样为凸四边形，路面视觉与碰撞使用同一组角点。切线朝向和相邻面支撑由运行时处理，接缝不能当作路缘。护栏为带真实多边形的独立collider；起飞和接收入口不放横栏。

## 操作与手感

| 意图 | PC | 手机 |
| --- | --- | --- |
| 地面油门／空中向前推进 | W | 左摇杆上推 |
| 地面转向／空中侧向推力 | A/D | 左摇杆左右 |
| 地面制动／空中水平反推 | S | 左摇杆下拉 |
| 抬升／下降缓冲 | 按住空格 | 按住右侧喷气 |
| 修正与反推同时做 | A/D+S | 左下／右下斜拉 |

喷气声音与喷流立即反馈，真实推力逐渐建立。松开抬升后仍有上冲惯性，再受重力下降。小方向输入细调，长输入明显改线；松手后温和收侧滑。真实姿态和运动方向易于理解。水平反推沿实际运动方向制动，归零保持，不反向倒飞；与修正、抬升可组合。

保留已认可的落地冲击，压沉一次再回稳。平顺落地保留大部分水平速度，轻微方向偏差由轮胎抓地逐渐修正。高架着陆后正前方就是下坡，避免停住找路。

镜头在起飞前展示落点。检修区预告上层入口时需适当抬高相机，看见高架顶面。下降时同时看见车与接收面；地平线稳定。引导仅当前阶段一句，细节放暂停帮助。

## 场景来源

通过连接的Blender MCP在Blender5.2.2 LTS构建独立场景Coastal_Interchange_v1，原RX100项目未覆盖。构建脚本为[build_coastal_interchange.py](../assets/blender/build_coastal_interchange.py)，独立源文件为[coastal-interchange.blend](../assets/blender/coastal-interchange.blend)。GLB和碰撞布局位于public/assets/coastal-interchange.*。

Blender画面捕获接口超时，后续两次execute请求亦超时。场景已成功导出，预览改由已保存的MCP源进行离线Blender相机渲染；另把library源存为可直接打开的正常.blend并检查重复叶片背面。此时未改变道路。随后回程实测暴露return-top窄急弯的偏移带翻折，独立凸性审计确认4个凹面。由于MCP接口仍超时，使用同一独立Blender源与构建脚本离线返修该接驳：原14面换为x=-34..6、z=14..40的宽阔平面回车区，补充方向箭头；总路面由167减为154。主线、护栏与补气数据保持原位。该步骤与最初MCP构建明确分列，不宣称全部返修都通过MCP完成。最终GLB顶点与凸性重新审计。预览与游戏实玩分开记录。

研究、技能与免费资源来源见[COASTAL_SCENE_RESEARCH.md](COASTAL_SCENE_RESEARCH.md)。

## 验收要求

1. 首次跨桥主要一个抬升动作完成；PC和手机都留有修正余地，预测足迹与真实落点相符。
2. 首跳接地后可以不停车接入缓弯。不得因曲面接缝、AABB假墙或坡度转换弹飞。
3. 从检修区抬升、修正、反推落台可以用一套组合操作完成；落台后方向自然朝向下坡。
4. 反推能明显缩短落点，水平归零后不倒飞。松开侧推后无需不断左右救车。
5. 下坡和出口连续驾驶完成，飞过出口不完成；普通地面旁路也可以完成。
6. 手机横屏至少两种尺寸验证双触点；取消、失焦、暂停与恢复不留卡键。触控模拟与物理手机明确区分。
7. 游戏原生输入证据与状态注入／固定步长诊断分列；保留首次失败及返修记录。主控必须实际试玩，不能只依据开发自动过关记录。
8. 最终生产包构建、来源许可和部署核对完成后更新cr3atL/car-flycontral的GitHub Pages。
