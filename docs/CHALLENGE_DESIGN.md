# 90秒挑战设计与实际规则

日期：2026-10-21。用户认可的第二轮操控为基线，src/config.js 中飞行调校未改。新内容使用独立 GameSession、位置障碍与可重复完整路线；CORE_ACCEPTANCE.md 由主控维护。

## 时间与页面

菜单→3秒倒计时→90秒驾驶→结算→再来一局。倒计时、暂停、2秒恢复倒数不计入驾驶时间。修复过渡计入驾驶时间。最终允许恰在90秒物理步完成的落地入账，此后物理/奖励停止；仍在空中的链清除并显示未入账金额。

暂停保留已提交有限脉冲的剩余时长，清按住状态、未消费按下边沿和后续输入；恢复不会额外延长脉冲。菜单、重开、撞毁和结果完全取消喷射。最佳成绩采用本机存储，异常时保持可玩及会话最佳。

## 按位置保留安全窗口

首组从倒计时开始就可见，固定在108m，行动距离45m。后续组只在名义遭遇前5秒、前组已处理、车辆接地、气压至少82%、上次落地至少2.8秒后提交。实际前置距离 max(170m, 当前速度×5s)，保证不是定时贴脸刷物。

撞毁后下一组至少等待7秒；重生在失败组末端后100m以上，气压恢复100%，速度沿用21m/s安全起步。重落地减速、自由表演与低气压会推迟后续安排，最多到76.5秒提交新组，之后略过；82秒开始清理未完成强制遭遇，82–90秒安全直道，87秒提示收尾。正常基础线的第9组约77.6秒遭遇、约80秒前后落地。

第一墙碰撞只免费纠正一次；它立即变为失败，不得反复领取通过分或无限借教学跳关。其余两次自动修复，下一次正式撞毁终止。已经入账的分保留，当前空中链清除。

## 追分与表现

每组完整通过独立100分、每组一次。青环450分与擦障300分进入当前飞行链：环按对象去重；擦障每组一次，离实体表面约0.04–0.65m的有效飞越后确认。动作与重复衰减沿用基线。类别为侧滚、前翻、后翻、环、擦障，组合每新增一类+0.5、最高3.0，再独立乘落地系数。

青色落地框用于选择和统计精准落地区，精准本身依靠1.2倍落地系数奖励，没有另增类别或重复加分。浮层最多四条稳定节点，只在新得分时增删；白/青/紫/金/RGB按单链0/300/700/1200/2000切档，入账时用落地金额快照保色，两秒隐藏不清链。RGB文字与有界粒子升级，精简档静态渐变；本地合成声音与落地反馈详见SCORE_FEEL.md。结果DOM仅进入结算时更新。

评级按GDD阈值0/6000/12000/20000/32000/45000配置，可在challenge-config.js调校。原始完整路线输出到 [challenge-trace.json](challenge-trace.json)：基础1980/C；八次双轴组合24120/S；增加侧向奖励27900/S；利用下一组已显示的恢复直道再表演一次、并正常跨障的高级路线49320/SSS，九组、32个完整动作、17次精准落地、四环一擦障、零撞毁。没有直接修改分数、速度、位置或气压；路线仅发推进、方向和特技输入。此结果证明SSS存在合法路径，不代表人工/手机易达。

## 复现与边界

npm run scenario:challenge -- --write。开发控制台startChallenge、setManual(true)、advanceWithPilot(94,{combo:true,rewards:true,extraFlights:true})驱动同一Simulation、调度和判定。setTimeScale(3)只改变开发时钟的固定步数，不改物理步长，供真实键盘与原生多触点完整90游戏秒回归。

浏览器回归含从按钮开始到结果的键盘与手机双触点全程，明确使用3倍测试时钟。并非真实手机或连续90秒满负载性能认证。已增加本地合成音与有界粒子，尚无自由偏航、高精模型和真实轮胎。所有内容本地运行，无新依赖、外网部署或防火墙改动。
