## 共享实现

- `src/vehicle-feedback.js` 是三个模式唯一的呈现实现。`src/sprint-visuals.js` 只保留旧验收脚本的类名导出；`world.js` 统一接线，旧调试字段保留兼容别名。
- 冷喷长度、核心和雾的强度同步三段基线，仍由实际 `forces` 决定。旋转/制动喷口沿车体真实姿态变换；没有施力就没有对应喷柱。地面冲洗按实际地面位置生成，运动后进入缺口也会隐藏。
- 补气事件增加观察元数据：单调序号、飞行编号、实际车位、来源种类及来源坐标。环由各模式的实际环提供坐标；特技从当时车旁汇入。没有硬编码三段环作为旧模式来源。多笔同帧事件分别保留 origin，按实际到账量分级；0和0.0814996等微量不显示整团能量球。没有新增账本项或改变奖励。
- `src/drive-feedback.js` 只观察速度和已交付的力。旧模式要求同一次飞行的grade0接地、实际正向地面电驱、正的净加速度和相对接地速度的真实增益；按接地速度至巡航的缺口归一化。纯超速减速、无增益、grade1、再次腾空或撞毁都不能制造恢复高潮。
- 接地前0.53秒不进入恢复速度层，之后最多展示1.2秒，仍要求当前有实际恢复。三段保留原顺势电驱资格和时序。附加FOV目标最多3°，地平线不滚转；中心24.5%–75.5%和HUD区域保持透明。
- 16组贴地光、40段距离尾迹、12颗补气球、12片喷气扬尘固定复用。补气最多保留4个短事件，序号去重集合有界。粒子以模拟时间/实际路程推进，暂停冻结，模式/重试/撞毁/结算/菜单清理。修正了完成三段后切换旧模式时仍受旧完成标记限制的呈现边界。
