## 飞行

持续推进仅对实际允许的主升力比例扣气。短喷仍按原18/10预付，被高度保护抑制的脉冲份额逐步退回主气压，以refund/ceiling-pulse单独记账；退回量不超过该次预付预算，实际退回受主表100限制，不计为空中补气。完全受保护的高空下降短喷不提交、不扣费，也不能借此授权持续喷气。旋转耗气、实得动作20/10/5、环请求30、主表100和单次腾空60上限不变。
