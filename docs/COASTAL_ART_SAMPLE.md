# 首处跨桥美术样段

2026年10月23日。本轮围绕已确认预览，优先完成首处跨桥约80米的游戏镜头。为让追尾镜头前方持续看到海岸，新海岸背景实际延伸至z330，旧装饰替换带为z62–335；道路、护栏和整条路线没有重排。其余区域仍保留上一版美术。

## 画面

跑车以低车身、连续肩线、轮拱和贴合座舱替换原方块造型。新增轮胎、轮圈、刹车盘、尾部扩散器及喷口；前轮随转向，轮胎随正倒车方向滚动。车身物理尺寸和原悬架、落地反馈保留。最终模型82个网格、33180三角形，边界约2.27×1.30×4.01米。

海岸改为不规则断崖、碎裂岩面、土壤草地过渡及贴地植被。实际游戏镜头返修后，将前方可见岸线延长，避免新场景只在车侧掠过。新增海岸145895三角形，不增加物理碰撞；三角形与真实路面驾驶空间的交叠检查未发现侵入。

动态海面使用多层波浪法线、近岸青绿到深海蓝渐变、环境反射、离散日光闪点、岸边及桥墩泡沫与桥面投影。已减轻首版整条发白的高光。统一暖色斜阳、天空环境光、车身及道路阴影和远景雾；背景天空平滑处理，避免低分辨率环境贴图放大成块状云。

车和海岸的几何通过实时Blender MCP制作，独立保存为roadster-gt.blend、firstspan-coast.blend。离线Blender仅用于源文件打包和模型检查，不将其渲染图冒充游戏画面。没有覆盖其他Blender项目。构建顺序与重建方式见[FIRSTSPAN_SOURCES.txt](../assets/blender/FIRSTSPAN_SOURCES.txt)。

新外部素材仅为[Poly Haven Kloppenheim 06 Pure Sky](https://polyhaven.com/a/kloppenheim_06_puresky)，遵循[CC0许可](https://polyhaven.com/license)，作者Greg Zaal、Jarod Guest；本地1K HDR为1173154字节。来源、用途和散列见[资源记录](../assets/third-party/polyhaven-kloppenheim06/README.md)。模型、海岸顶点色和海面着色器为本轮原创，运行时不请求外部素材服务。

## 操作修订

- 地面持续S或摇杆向后，先制动、过零后平顺倒车，无需第二次输入。空中反推保持只减水平速度到零。
- 对实际护栏、路面侧边和底部做连续接触处理。接触阻挡、减速、滑动，玩家可以倒车退出；严重接地保留冲击和操控，不因碰撞传送。
- 出界或落出场地仍自动回最近安全点；手动R及暂停内复位保留。自动恢复同步重置追尾镜头，修复恢复后侧向绕车的问题。
- 喷气推力、重力、气压、输入映射、声音及落地压沉规则没有重新调参，得分仍未实现。

## 验收

开发与主控分别完成186/186规则检查。主控逐项验证51份最终冻结记录、生产资产副本及最终主包；原60份基线文件中57份未变，3份修改为本轮授权的主入口、模拟及呈现整合。原始道路GLB和布局文件逐字节不变，仍为154块路面、182段护栏。

开发原生键盘和667×375、844×390双触点检查在最终生产包完成整条主线，另有地面绕行、接触后倒退、自动出界恢复及触点生命周期记录。控制器只读状态辅助操作，没有推进仿真或写入车辆状态，不等同人工易用性研究。真实系统后台在无头环境没有触发blur，只有合成事件接线通过。

主控普通入口实际操作PC及667布局：短喷跨桥、真实接收路接地、继续行驶、地面连续倒车、碰栏后退出、掉出地图自动恢复及镜头方向。手机布局使用鼠标按住屏幕控件，双指另由开发原生触控记录补充。初次手机起飞较晚未到对岸的失败保留，重试及最终生产首跳通过，不宣称所有新玩家能一次完成。

本机首轮候选使用默认根路径，主包roadster-6L2jcyue.js，SHA256 b08e7573f55d65a823f808ff2e91e24eb68cb28043d5df28500c470de2f96e7f。其冻结与本机实玩记录保留原名。发布工作流使用相对路径；主控独立以 `npm run build -- --base=./` 重建得到roadster-BAcCjqFS.js，SHA256 cec98cdcc5d3bec360d550961746c97a62f694a7ff512110c52c425051829bb3，与实际云端产物及线上精确一致。213份文件中208份逐字节一致，5份仅CR/LF差异，涉及JSON另校验解析内容相等。首次错误地将根路径包与相对路径包比较的失败报告另存，不将其冒称资源全通过。
