# 停车场不让你走

独立目标片段：穿过停车架、空中补气、落到黄压板、弹射清洁车、砸墙放桥，最后驶过出口才完成。主菜单以此为主入口，原90秒挑战、连续三段、自由练习保留。最终包 `index-BJJYocJ2.js`，SHA256 `7f336f7bee01486d1bd286cda4e6d64d5fb749bec83a1f51426200bba3278e92`，相对路径构建。源码/测试哈希见 `parking-runtime-freeze.json`；主控负责独立验收、Git和Pages。

## 真实空间与操控

新模式从z=-40开始，给地面选线与收势留时间。停车架位于145米，有可见8米高机械基座，不能从中线地面钻过；两侧约7–8米横向位置是宽路。车在地面选线，起飞后没有新增横移。中间35度斜开口以车身OBB在开口坐标内的投影判定，考虑pitch、yaw、roll和沿深度的坡度；架体是有限实体，架顶之外不碰无形墙。可见几何与判定共用配置。轻擦破护板并减速8%，严重相交沿用撞毁。

玩家始终自己推进、旋转与松手；没有自动起飞、补圈、自动切轴或姿态锁。黄区给约1秒的起飞提示，空中再按当前高度/速度推算的到架趋势提醒继续推进、释放或补喷；不以墙钟毫秒假定仿真输入。中线适合松开推进后轻侧滚贴斜架；宽路线无需特技。原三轴、限高、耗气、补气、落地等级及约0.41米车辆压沉常量未改。

主环位于165米、中心高度15米，半径9.8米覆盖宽路。按车中心穿过环平面且在可见环内触发，每飞行一次，调用原receiveSupply请求30，实际量受主表100及腾空总60限制。正常一跳环后到接地约2秒；漏环可继续，开机关不检查环或圈数。

## 重压与可驾驶出口

有效黄板是x±10.5、z220–310，全部画成黄色，不另画较小的假判定核心。外围板和两侧实路仍可接车。板下有可见机坑，板压沉与连杆不会被静态路面遮住。车辆原接地弹簧、地平线和声效保持原样。

机关强度为单位质量能量代理，取缓冲介入前最大向下速度的平方一半，以及本次飞行最高点到落点的势能9.81×落差，两者较大值。门槛集中为80J/kg。车中心命中、轮向下、现有非撞毁落地即可；现有精准门槛只用于原评分奖励，不作为通关锁。每次飞行的一次接地只触发一次，地面悬挂不会重复触发。

真实输入实测：PC宽路约132.88J/kg、捷径151.06J/kg；667触屏约168.64、844触屏151.06，均成功。短喷轻落约61.10，只抬托架并回落；本地重试普通推进后约90.15，可成功。缓冲后的实际接地约3.9m/s仍能重压，不需要飞到24米以上。

接地后前0.2秒压板压沉、连杆绷紧；0.3秒托架发射。清洁车沿确定轨迹前进，实体前缘真正到墙时才发出撞墙事件，约接地后0.91秒。墙裂开留碎片，清洁车残骸留在旁边，并有短尾迹供肉眼追踪。1.1–2秒维修桥落下，撞墙已经发生且桥锁定后才把原缺口变成实际ground。玩家不被切过场或停控；开墙不结算，继续驶过372–440米桥面，驶过510米出口门后25米才显示完成。

原接地声保留首拍。模式内机械绷紧、弹射、破墙、锁桥声音共用已有有界声音池，期间计分音避让，不改其他模式声音。无特技得分时隐藏大0分，以“逃出停车场”为主反馈；有实际分数则正常保留。

## 失败与恢复

架前撞毁回入口；过架后的落偏或轻落可沿可见前向维修标记回到架后160米，不需倒车，也不必重穿架。维修黄区176–194米建议推进约0.7秒。实际原速轻落—回环—再起飞—重压—出口已完成。漏环未阻止本地重试开路。

机关启动后锁定本次成功进度；即使撞毁仍继续完成墙/桥事件。已开路后的恢复点在桥后，不重放机关。原速验证了启动时暂停冻结、恢复后开桥，再故意撞出边界，恢复后仍能过出口；heavy事件仅一次。R整段重开、暂停重开、返回主菜单及旧三模式入口保持可用。
