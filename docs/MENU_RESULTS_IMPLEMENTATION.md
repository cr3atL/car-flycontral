## 界面

90秒成绩从右侧展开，保留结束车辆与场景。先场景局部压暗，再等级、分数；C到SSS沿用原评级和独有名称，S/SS加强短促冲击，SSS仅一次短RGB。重试/菜单无需等待动画，首次进入聚焦重试，系统减弱动态设置取消这些动画。

默认三项为真实最高入账连击、精准落地、通过组；其余实际统计收进详细数据。只在实际发生时显示修复耗尽、未落地入账分。开局快照原best，结果读取GameSession实际总分与newBest：有旧纪录才算差值，首次正分只显示新纪录。未破纪录显示距最佳和原最佳；无历史零分不造最佳。没有新增或迁移存储，也没有混入练习/三段成绩。

练习与三段保留原首拍、入账数、计算式和飞入总分，2.53秒后接替为单份轻量结束区；旧combo和重试入口收起，顶部重复总分隐藏。错误落地保留真实原因。Sprint完成会冻结模拟时钟，界面独立时钟补完显示窗口；暂停不推进该界面时钟。重试复用原模式重开，菜单可直接返回。镜头与世界代码未改动。
