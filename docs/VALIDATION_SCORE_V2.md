## 活跃效果的桌面测量

Windows Edge / WebGL2，1280×720，AMD Radeon(TM) Graphics、ANGLE Direct3D11。串行浏览器测试，丰富档连续两次真实Space/Q/W组合、RGB与2430入账，约11.45秒、458个25ms样本：

| 指标 | 丰富（两次组合） | 精简（一次组合） |
| --- | ---: | ---: |
| 采样时长 | 11.45s | 5.73s |
| 中位FPS | 60.00 | 60.00 |
| Babylon渲染耗时中位 / P95 | 1.90 / 3.00ms | 1.90 / 2.60ms |
| 峰值绘制调用 | 90 | 90 |
| 实测峰值活动粒子 / 环 | 90 / 2 | 6 / 1 |
| 固定场景网格 | 155 | 155 |
| 实测峰值声部 | 5 / 8 | 5 / 8 |

渲染耗时是Babylon frameTimeCounter，包含场景渲染段，不等同于整个浏览器帧预算；效果质量使用引擎真实帧间隔。粒子是独立2D Canvas，因此不增加Babylon网格/绘制调用。运行时粒子上限丰富128、移动视宽96、精简16；环8。手机模拟DPR2时特效画布仍不超过1.25。

音频后主增益Analyser在实际事件期间测到峰值约0.034、多个非零帧，削波帧0；一个AudioContext、八个固定声部、无丢弃。确认了真实浏览器信号链输出，不宣称已通过物理扬声器听感评测。静音/暂停/后台后的输出被取消和挂起，恢复不补播旧队列。

活动样本原始指标另存[score-feedback-metrics.json](score-feedback-metrics.json)。层级与Text节点复用修正后，RGB/入账、正常开局与两种重开声音、4320 RGB入账等相关用例均已定向复测通过。
