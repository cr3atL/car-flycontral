# Roadster 喷气跑车核心原型设计

版本：0.1。日期：2026年10月23日。首版核心已实现，实际验收与未验证范围见 [主控验收记录](CORE_ACCEPTANCE.md)。本文保留设计基准与首轮调校记录。

玩家驾驶一辆带有喷气能力的跑车，自己控制加速、起飞、空中改道和降落，在道路与平台之间选择通往出口的路线。高速短喷跨越与低速主动升空使用同一套运动规则，车辆的速度、惯性和剩余气压共同决定能到哪里。

本原型面向PC和手机横屏，单人，继续使用Babylon.js。先验证一辆车、一个小场地和三条路线。保留得分系统的后续接入位置，计分规则另行设计。

Roadster 2提供喷气跑车的玩法灵感；本文中的操控辅助、推力、气压和路线尺寸均为游戏设计，不作为实车性能描述。

## 核心体验

一次完整驾驶应当连贯地完成：观察前路、加速、选择起飞点、用喷气改变轨迹、确定落点、接地后继续驾驶。

同一个出口允许不同走法：保持高速直接跨越；先落到低平台，再次起飞；主动爬升到高平台，从高处切入出口。玩家可以停车观察，也可以在飞偏后改变目的地。

车辆具有可预测的惯性。起飞保留地面速度，松开喷气后继续沿当前速度运动并受重力下落，改变方向和制动都需要过程。辅助系统负责协调姿态，玩家主要控制运动方向、速度和高度。

本设计替代旧版核心中的自动前进、独立三轴旋转、固定90秒流程和指定机关动作链。旧版气压、限高、特技补气、精准落地和评分阈值均不自动成为新原型规则。现有落地反馈可供参考，最终按连续驾驶需要重新调校。

现有版本和历史设计保留。新核心使用独立入口 `roadster.html`，新旧模式各自使用对应的输入和运动规则。

## PC和手机操作

| 驾驶意图 | PC | 手机横屏 |
| --- | --- | --- |
| 加速或空中向前推进 | W | 左摇杆向前 |
| 左右转向或侧向修正 | A、D | 左摇杆左右 |
| 地面刹车或空中反推 | S | 左摇杆向后 |
| 持续喷气抬升 | 按住空格 | 按住右侧喷气按钮 |
| 停止主动抬升 | 松开空格 | 松开喷气按钮 |
| 暂停 | Esc | 暂停按钮 |
| 复位到最近安全位置 | R | 暂停内的复位按钮 |
| 整场重开 | 暂停内选择重开 | 暂停内选择重开 |

PC支持W和A/D、S和A/D分别与空格组合。相反方向同时输入时该轴归零；松开后按仍然有效的方向恢复。键盘和触控使用同一套运动规则。

### 手机双拇指操作

左手负责方向与加减速，右手负责喷气。摇杆向前加速、向后制动，横向分量控制左右方向；斜推可以同时加速与转向。左右与前后分量独立计算，斜推不因圆形归一化而削弱其中一个轴的最大输入。

摇杆设小回中区，回中即松开方向和油门。拖动触点由摇杆持续跟踪，越过可见边界时保持最大输入，不跳转到其他按钮；手指抬起、触点取消或应用失焦时归零。喷气按钮具有同样的持续按住和释放规则。

两个触点必须能同时工作，包括斜推摇杆并持续喷气。无需先释放喷气再调整方向，也不需要第三根手指。暂停、切换横竖屏和恢复前台后，所有输入先清零，重新触碰才生效。竖屏暂停驾驶并提示横屏。

## 地面驾驶

W或摇杆前推控制电机油门。松开后依靠惯性滑行并逐渐减速，车辆不会自行恢复巡航速度。普通轮胎驱动不消耗喷气气压。

低速转向灵活，高速时转向幅度逐渐收紧。松开左右输入后前轮回正，车辆保持当前行驶方向。原型允许轻微轮胎滑移，暂不加入独立漂移操作。

S或摇杆后推首先制动。制动持续按住至停稳时保持停车，不自动倒车；回中或松开后，再次向后输入才进入倒车。倒车期间再次松开、向前输入时，先制动至停稳再向前起步。方向输入只改变车轮转角，停车时不会原地旋转车身。

车辆允许停在平台上观察路线、调整位置和倒车。平台边缘可见几何与碰撞一致，不使用看不见的护栏维持路线。

## 喷气抬升

按住喷气按钮持续产生向上的推力，松开后快速收掉。推力建立应有短促的声音、喷流和悬挂卸载反馈，但不设置会吞掉短按的动作前摇。

地面起飞完整保留已有水平速度。空中继续按住时先抵消下降速度，再产生上升速度，车辆不会在按键瞬间停住或跳高。松开后保留已有上升或下降速度，重力持续生效。

主动抬升以世界竖直向上为主，不随辅助倾斜把升力大幅甩向侧面。姿态辅助保持轮子大致朝下，允许与加减速、转弯对应的少量俯仰和侧倾。

| 组合 | 用途 |
| --- | --- |
| 仅按喷气 | 停车起飞、抬高轨迹、减缓下降 |
| 向前输入加喷气 | 向前推进并爬升、延长跨越 |
| 左右输入加喷气 | 抬升的同时修改路线 |
| 向后输入加喷气 | 减小水平速度并托住下降，接近落点 |

持续升空和短暂悬停依靠玩家分配气压；没有一键悬停或高度锁定。原型不沿用旧版24米软限高和30米上限，正常活动高度由推力、重力与气压限制。场地外的复位边界只防止无限坠落，不参与正常飞行操控。

## 空中转向与推进

左右输入代表改变实际路线。侧向喷口施力后，水平速度方向逐渐改变，形成弧线；车头和车身倾斜跟随运动趋势。空中不提供独立的侧滚、翻转或车头空转按键。

有明显水平速度时，左右按当前行进方向解释。接近静止时沿最近稳定的车头方向确定左右，避免速度很小时方向突然翻转。松开方向停止主动侧推，保留已经形成的水平速度，姿态逐渐回稳。

轻点方向用于小幅修改落点，持续输入形成转弯。同等侧推下，高速转弯半径更大，玩家需要提前选线。低速时可以向侧面挪动；一旦形成移动，控制自然过渡到沿运动方向转弯。

空中向前输入使用前向喷气，沿辅助系统维持的前进方向增加水平速度。该方向平滑变化，不能因车头视觉回正而瞬间折转速度。向前、左右和抬升可以同时工作，并分别消耗气压。

第三人称镜头平滑跟随车辆水平行进方向。镜头追赶期间不改变输入的左右定义；手动绕镜头和第一人称视角不在本轮范围内。

## 反推制动与落地

空中向后输入，对准当前水平速度的反方向施加制动力。短按缩短预计落点，持续按住明显减速。接近零速时停止继续反向加速；持续按住不会把车推成倒飞。反推本身不冻结车辆位置，也不消除下降速度。

向后制动可以与左右修正及抬升同时使用。玩家用反推决定落在哪里，用抬升调节下降速度和落地冲击。

落地后悬挂压缩、轮胎接触声和镜头短促下沉共同表现重量，随后恢复抓地。玩家全程保有输入，按住油门可以接地后继续起步。禁止通过不可操作的落地动画打断连续驾驶。

本轮只区分可继续驾驶的接触、明显危险的接触和撞毁。正常轮向下接地有容错，允许不完美的落地继续行驶；翻覆、严重碰撞和跌出场地需要复位。不使用旧版精准角度、速度或计分档位决定通关。具体碰撞阈值随原型调校，验收以正常路线可控、危险接触反馈一致为准。

## 气压与落点反馈

原型使用一个清楚可见的气压表。抬升、空中前推、侧推和反推共享气压，同时使用时合计消耗。计量数值和消耗率属于实现阶段的调校参数，以三条路线的可完成性为约束。

稳定落地且未使用喷气时开始恢复气压；正常道路恢复较慢，平台上的可见补气区域恢复较快。启用喷气即停止恢复，避免贴地喷气形成无限供给。平台无需指定朝向或精准停靠，驶入可见范围即按实际接地状态恢复。

满气应支持路线一的一次跨越并留出一次有效修正，也应支持路线三的一次爬升、转向和减速落地。路线二允许在中继平台补气后继续。多轴同时使用必须有可见消耗，不能因辅助系统而免费产生大幅路线变化。

气压耗尽后主动喷气停止，车辆继续按惯性和重力运动，已有轮胎驱动仍可使用。场地下层道路承接可挽救的失误；并非所有耗尽位置都保证安全。原型暂不加入空中补气环、特技补气、隐藏缓冲气罐或自动救援喷气。

### 必要画面信息

地面常驻速度和气压，暂停入口保持可见。飞行时增加预计轨迹和车辆大小的落点标记；预测无安全支撑面时清楚显示危险。

预测按“持续保持当前输入”计算。松手、改变方向、反推和气压变化后立即更新；考虑气压不足导致推力停止的情况，不画出无法执行的无限喷气路线。预计下降冲击较大时标记闪动，配合增强的风声，避免只依靠颜色表达风险。

着陆点以车辆实际占地和支撑面判断，不能把墙面、平台侧面、平台下方的地面错误显示为同一个安全落点。预测、碰撞和场地尺寸使用一致的几何定义。

三个目的地用地形、高度和可见平台表达。首次进入只给短操作提示，完成对应动作后收起；完整操作放在暂停界面。画面不堆叠步骤编号、路线名称、特技标签和重复说明。

喷流、车身侧倾和声音对应实际生效的推力；气压耗尽时关闭相应喷流。加速有风声增强，反推有方向明确的喷气反馈，落地首拍突出轮胎和悬挂。效果需要帮助判断操控状态。

采用第三人称可读的开放试验峡谷。起点即可看到对岸出口，接近断口前能看清左侧低平台、右侧高平台和下层回路。入口、平台和出口使用清楚的轮廓与高度差，不通过机关解锁路线。

2026年10月23日首轮实玩调校：低平台的纵向范围扩大为z=110至150，实际24×40米；高平台扩大为z=126至162，实际30×36米。高度、横向位置和中部补气区保持。上表保留初始搭建尺寸供对照；当前实现以同源Blender导出布局为准。调整用于增加修正和落地的容错，三条路线的用途不变。回程平路在z=25与坡道平接。

### 路线一 高速直跨

从起点沿主直道加速，在断口前短喷起飞，保留水平速度跨到对岸道路，接地后继续驶向出口。

这是首次尝试的推荐路线。默认车头指向直道，前方开阔，成功不要求左右修正、精确毫秒输入或额外特技。喷气时机和持续时间要有连续容错区间，不能只有一个极窄的正确按法。

玩家学习速度如何影响距离，以及松开喷气后如何自然落地。起跳不足时可继续喷气修正，气压不足且仍在接应范围内时可落到下层道路。

### 路线二 中继起降

在直道后半段提前向左选线，起飞落到4米高的中继平台。用反推缩短落点，接地后可停车观察和补气，再调整车头朝向对岸起飞。

平台应当有足够空间停稳和重新起步，补气区域放在平台中部，避免把玩家引向边缘。第二跳到对岸不要求先回主直道，也不要求在平台上强行掉头。

玩家学习控制落点、在安全位置恢复气压，以及主动选择第二次起跳。完成路线二必须包括中继平台上的真实接地，飞过平台上空不算验证了这条路线。

### 路线三 高位切入

从直道右侧主动起飞，结合前推和抬升爬向10米高平台。用左右修正对准平台，再用反推缩短落点、用抬升控制下降，停稳或低速接地。

接地后可补气和调整方向，随后驶出平台朝出口降落；利用高度滑落或少量喷气衔接对岸道路，继续通过出口。

这条路线验证主动升空、横向改道和反推的组合价值。高平台应当从起点和直道上可见，具有足够大的可降落表面；不要求原地悬停、穿小孔或独立旋转车身。完成验证必须真实接地高平台，再到达出口。

### 路线切换与终点

平台和主路之间保持开放空间，玩家可以临时改落点。三条路线是验证样本，不是锁定的任务脚本；不以隐藏路线阶段阻止改道。

车辆落在对岸道路并沿道路通过出口门后完成。飞过出口上空不触发完成。完成反馈保持简短，可立即重开或返回入口，不显示尚未设计的评分、评级和假分数。

## 失败与重试

起点、两个平台和对岸安全路面提供恢复位置。到达后需在安全表面稳定接地、远离边缘才更新恢复点，防止把擦边接触或一次弹跳记录为安全位置。

掉出接应道路和场地边界、翻覆或严重碰撞后，短暂反馈并复位到最近已确认的安全位置，速度归零、气压补满、方向朝向可驾驶空间。输入先清零，避免恢复瞬间再次冲出边缘。目标是约2秒内可以重新操作，具体以加载和镜头稳定情况调校。

玩家也可主动复位。整场重开回起点并清除本次路线验证记录。暂停冻结车辆、气压和场地状态，恢复时不补算后台经过的时间。

轻微擦碰允许继续驾驶，下层道路上的合法接地不自动判失败。玩家可以沿回程坡道重试，也可以主动复位；已经到达的平台恢复点不会因飞偏而丢失。

## 开发范围

### 本轮实现内容

1. 独立的新核心原型入口，一辆原创灰盒跑车，第三人称跟随镜头。
2. 手动油门、惯性滑行、转向、制动和倒车。
3. 持续抬升、空中前推、侧向修正、反推，以及协调车身姿态的辅助。
4. PC键盘和手机双拇指触控，包含取消触点、失焦和暂停的正确释放。
5. 共享气压、地面恢复和平台补气区域。
6. 上述三条路线、下层回程、出口、恢复点与重开。
7. 速度与气压显示、落点预测、简短首次提示，以及对应真实推力和落地的基础声画反馈。
8. 支持验收的输入、运动和路线记录；记录不直接产生分数。

先完成地面驾驶和高速直跨，再验证低平台的两次起降，最后验证高平台组合操作。三条路线均通过后，再集中调整镜头、声音和落地衔接。

### 后续再设计的内容

计分公式、连击、奖励倍率、C至SSS评级、得分粒子和结算界面；独立特技旋转、空中补气奖励、漂移；停车场机关、破坏链、城市任务、追逐和关卡剧情；第一人称、车辆改装和内容扩展。

本轮不进行大规模城市美术重做或专项性能优化，但必须保证输入不会因界面刷新而丢失、卡住或重复触发。旧版本已发布内容无需随原型设计迁移或重新发布。

## 得分系统接入边界

得分系统属于后续玩法的一部分。原型先能区分起飞、持续飞行、路线变化、反推减速、有效接地、进入平台、驶过出口、复位和撞毁等行为，并记录必要的速度、位置、气压和接触结果。

同一次实际接触不应因悬挂抖动重复记录多次落地。平台接地与飞越分开，主动复位与成功驾驶分开。记录用于以后设计和验证奖励，不代表这些行为必然加分。

本轮不定分值，不继承旧版空翻计分、精准落地倍率、气压奖励或评级门槛，也不以“做动作才能恢复气压”约束基础驾驶。后续再讨论如何奖励新路线、连贯驾驶、有效修正和风险选择。

## 验收标准

以下是本原型的通过标准，实际结果以主控验收记录为准；未开展的新玩家研究或实体手机检查需单独标明。

### 操作与运动

| 项目 | 通过条件 |
| --- | --- |
| 手动驾驶 | 不输入油门不会自行加速；可停车、保持刹车、重新输入倒车，再向前起步 |
| 惯性 | 地面滑行和起飞均保留水平速度；松开喷气不瞬停，按住喷气不瞬移 |
| 空中路线 | 左右输入改变实际轨迹与落点；没有只有车头转动、路线不变的假转向 |
| 反推 | 在不同朝向下均减小水平速度，持续按住至接近零速不反向弹走 |
| 组合 | 前推加转向加抬升、反推加转向加抬升均有效，切换和松手无动作队列或残留输入 |
| 气压 | 所有实际喷气均计入消耗；空中和喷气期间不地面恢复；耗尽后保留合法惯性和重力 |
| 接地续跑 | 接地时保有控制，悬挂反馈后可继续转向和加速，无强制停控动画 |

### 场地与路线

PC和手机分别完成下列操作，每条路线至少连续验证3次；失败应记录原因并在修复后重试，不能用单次偶然成功替代容错验证。

| 项目 | 实际试玩通过条件 |
| --- | --- |
| 路线一 | 从起点手动加速、跨过主断口、对岸接地并驶过出口；相邻的起飞时机和不同短喷时长也可完成 |
| 路线二 | 真实接地低平台、恢复气压、再次起飞、对岸接地并通过出口 |
| 路线三 | 主动爬升并真实接地高平台，使用过空中修正和反推，再离开高平台通过出口 |
| 临时改道 | 至少一次起飞后修改目的地并安全接地，落点预测随操作更新 |
| 可恢复失误 | 至少一次起跳不足后落到下层道路，并完全依靠地面驾驶返回起点 |
| 撞毁与复位 | 起点和平台后的撞毁均恢复到正确安全位置，气压、速度、朝向和输入状态一致 |
| 终点 | 对岸接地后驶过出口才完成；飞越出口上空和驶过下层道路不误触发 |

### 手机与反馈

| 项目 | 通过条件 |
| --- | --- |
| 双拇指 | 摇杆与喷气可持续同时输入，斜推不丢油门或方向，无需第三指完成三条路线 |
| 释放 | 触点抬起、取消、滑出区域后抬起、暂停和切后台后无持续喷气或转向残留 |
| 适配 | 至少在667×375和844×390横屏检查安全区、可达性和前路遮挡；实际触控验收与尺寸模拟分别记录 |
| 预测 | 持续当前输入时能正确预告目标表面；释放、制动和耗尽气压后及时更新；边缘和无地面风险明确 |
| 声画 | 抬升、侧推、反推与实际施力对应，落地冲击明确，同时不遮住落点或打断控制 |
| 引导 | 无口头指导也能找到油门、喷气、刹车，理解出口以及至少一个备用平台 |

可用性检查目标：邀请至少3名未参与设计的试玩者，每人先尝试约2分钟，至少2人能独立完成一次主线跨越与安全落地，并能说出一个想尝试的备用路线。若未安排新玩家试玩，应明确标记该项尚未验证。

### 验证方式与交付

使用普通键盘或触控输入完成原速试玩，保留起飞、修正、接地、气压和完成状态记录。单元测试与固定输入重放用于检查规则一致性，不能替代连续操控和手机双拇指的实际验收。

手机模拟器或浏览器触屏测试应注明环境，不能作为实体手机触感的结论。开发和验收期间不通过注入车辆位置、速度、气压或直接触发完成来证明路线可玩。

交付应包含可运行原型、实际调校参数、PC与手机验收结果、已知问题和原速试玩证据。旧版测试通过数与历史试玩记录仅作回归参考，不计入本轮通过结果。

本原型成立的判断是：玩家第一次能理解怎样飞过去，随后愿意换一种路线，飞偏时能够用操作改变结果，落地后还能顺畅继续驾驶。得分规则在这个基础上继续讨论。
